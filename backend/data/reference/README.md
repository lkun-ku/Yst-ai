# `data/reference/` —— 参考资料（**不进知识库**）

本目录是**人工/半自动收集的参考材料**，与 `data/official/` 严格分开：

| | `data/official/` | `data/reference/`（本目录） |
| --- | --- | --- |
| 是否被 `kb_corpus` 摄入 | **是**（递归抓 `*.md`） | **否**（在 `official_kb_dir` 之外） |
| 谁能进 | 官方语料，且经人工确认 | 任何参考材料 |
| 内容进不进检索 | 进 | **不进** |

> ⚠️ **为什么必须分开**：`kb_corpus.iter_source_files()` 用 `rglob("*.md")` 递归遍历语料根目录。
> 把 `.md` 放进 `data/official/` 会**自动进知识库** —— 那是一个会影响检索质量与引用校验的
> 产品决定，**不该由"文件放哪儿"顺手决定**。要入库，请人工把它们整理进
> `data/official/{laws,regulations,syllabus}/`。

## 目录结构

```
data/reference/
├── README.md              # 本文件：来源、权威级别、用途、未获取清单
├── 大纲/                  # 官方《考试大纲》全文（官方公开，免费下载）
├── 评分参考/              # 评分标准 / 采分点的**事实性要点 + 来源链接**（非全文）
└── 清单/                  # 需要人工引入的东西：链接、字段模板、缺口说明
```

## 权威级别（每份文件头部都必须标注）

| 级别 | 含义 | 用法 |
| --- | --- | --- |
| **官方** | 教育部教育考试院 / 考试标准原文 | 可直接入库、可作为判据基准 |
| **半官方** | 教辅/机构整理，内容为官方规则的转述 | 仅作参考，不能当判据基准 |
| **回忆版** | 考生回忆（官方不发布真题） | ⚠️ 有记忆偏差，须交叉比对后使用 |

## 已知的**无法获取**清单（避免重复找）

| 想要 | 状态 | 说明 |
| --- | --- | --- |
