# G3 唯一性投票基准（真实模型下的**误杀率**）

- 生成时间：2026-06-11T19:26:33　题数 30（有效 30）
- 模型：LLM=real　每次投票数：3
- 数据：`eval/datasets/g3_唯一性/官方题样本.json`（官方池 PASSED 的题）

> ⚠️ 本表喂的是**已审校的官方题** —— 所以 `blocked_rate` 是**误杀率**，不是拦截战绩。
> G3 是 N 倍成本且默认关闭的闸门：它该不该开、投几次票，取决于它拦掉多少好题。

| 指标 | 值 | 读法 |
| --- | --- | --- |
| agree_rate（N 次盲答一致） | 1.0 | 低 → 答案确实有歧义，或模型不稳 |
| matches_rate（与自带答案相符） | 1.0 | 低 → 题目答案错**或**模型答错，二者无法只凭它区分 |
| **blocked_rate（误杀率）** | **0.0** | 这就是「该不该默认关闭」的判据 |
| invalid_rate（投票全无效） | 0.0 | 高 → 接口在抖，本表不可信 |
