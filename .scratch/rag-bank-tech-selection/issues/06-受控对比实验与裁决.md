# 06: 受控对比实验与裁决

- Status: ready-for-agent
- Type: task
- Blocked by: 05
- 关联：`.scratch/rag-bank-tech-selection/spec.md`、`backend/eval/`、ADR-0009

## What to build

用可复现的评测 harness 对三路线做**受控对比**，产出量化裁决依据，而非凭直觉选型：

- 双测试集（教资真实资料 + 技术教程），覆盖跨文档出题真实形态。
- LLM-as-judge 五维评分（事实性 / 考点覆盖 / 区分度 / 表述 / 溯源），输出可比。
- 三路线对比 runner：默认 `EMBEDDING_MODE/LLM_MODE=fake` 离线跑通，可切 `--real` 真实跑。
- 输出 JSON + MD 报告，结论回填选型文档。

**裁决结论（实验产出）**：路线②③ 质量与成本逐项相等（72 次 LLM 调用 / 38354 字符），证明**框架对出题效果中立**；质量增益来自"质量闭环模式"而非框架。
