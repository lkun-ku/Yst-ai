# 05: 发起闯关局

**Labels:** ready-for-agent

**What to build:**

考生按模块或考点发起一次闯关局，固定 10 题一次下发到本地，作答期间不请求网络；题目在一局内不重复、不连续出现两个相同题型（用户故事 7–15）。

- 入参为模块（或考点）与题量；出参含闯关局标识、题目集合（每题含题干、选项、正确答案、解析、考点归属、AIGC 标识、来源标识）、本局题序（实现决策 4）。
- 一局固定 10 题；一局内题目不重复；不出现连续两个相同题型（用户故事 9–11）。
- 题目一次拉取并本地缓存，弱网 / 退出可续答（用户故事 12–14）。
- 本局进度与已用题量可见（用户故事 15）。

**Blocked by:** 02 — 考生身份与游客模式；04 — 题目实体与离线题目池供给（先种子题目）

**Status:** ready-for-agent

**验收清单：**

- [ ] 按模块或考点均可发起，返回闯关局标识与完整题目集合
- [ ] 一局固定 10 题，一局内不重复，无连续两个相同题型
- [ ] 题目一次下发，作答期间无额外网络请求
- [ ] 退出后重新打开可续答，进度不丢
- [ ] 进度与已用题量对考生可见
