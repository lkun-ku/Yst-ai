# 13 题目纠错与审校队列

## 概述
考生报告题目错误（答案/解析/考点归属）→ 进审校队列；提供最小审校后台（待审队列、通过/驳回、错误报告处理）；结构化校验（schema、答案唯一、选项互斥、解析非空、考点归属存在；不通过即弃）。文化素养模块抽检比例最高。横切：内容安全输入/输出检测真实接入。

## 范围
- in：纠错提交入队、最小审校后台、结构化校验、文化素养最高抽检比例配置、内容安全输入/输出检测接入（微信内容安全 API）。
- out：AI 自动修题、完整 Web 管理后台仪表盘。

## 依赖（Blocked by）
- 06（纠错入口数据来自票 06）

## 验收标准（Acceptance Criteria）
- 纠错入口提交进入审校队列（错误类型：答案/解析/考点归属）。
- 最小后台：待审队列、通过/驳回、错误报告处理。
- 结构化校验覆盖：schema、答案唯一、选项互斥、解析非空、考点归属存在；不通过即弃（Implementation 19-20）。
- 文化素养模块抽检比例最高（常识/历史/科技最易出错，配置项可调）。
- 内容安全：考生输入侧（纠错文本、考期输入等）与生成内容输出侧均接入检测，未通过不得展示或入库（Implementation 29）。
