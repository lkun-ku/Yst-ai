# 03 发起闯关与题目拉取

## 概述
实现「开始闯关局」接口与模块/考点选择入口：按模块或考点发起，固定题量（默认 10），**一局全部题目一次下发**并在客户端缓存；同局题目不重复、不连续两个相同题型。

## 范围
- in：开始闯关局接口（入参：模块/考点 + 题量；出参：局标识 + 题目集合 + 题序）、题目字段（题干/选项/正确答案/解析/考点归属/AIGC 标识/来源标识）、模块与考点选择入口、同局不重复与不连续同题型约束、接口契约文档（路径/请求/响应 schema）。
- out：答题判定（票 06）、本地持久化（票 07）、实时生成（票 14）。

## 依赖（Blocked by）
- 01、04

## 验收标准（Acceptance Criteria）
- 按模块发起返回该模块题目；按考点发起返回该考点题目。
- 一局题量可配（默认 10），全部题目一次下发，作答期间不再请求网络。
- 同局题目不重复；不连续出现两个相同题型。
- 返回字段含：题干、选项、正确答案、解析、考点归属、AIGC 标识位、来源标识（池化/实时）、题序。
- 接口契约以文档形式明确（路径、请求/响应 schema），作为主测试接缝 A。
