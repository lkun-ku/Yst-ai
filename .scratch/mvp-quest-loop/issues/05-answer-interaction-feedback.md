# 05 答题交互与即时反馈

## 概述
前端答题流：选中选项即瞬时高亮对错；展示本局进度与已用题量；解析默认收起、可展开；多选题四态展示依赖票 06 的判定结果；弱网/退出不白屏（持久化协作票 07）。题目卡片/AIGC 标识位必现（合规横切）。

## 范围
- in：选中即时高亮、进度显示、解析展开交互、四态展示、弱网/退出保护衔接、AIGC 标识位在题目卡片展示。
- out：判定逻辑（票 06）、本地持久化实现（票 07）。

## 依赖（Blocked by）
- 03

## 验收标准（Acceptance Criteria）
- 选中选项后正确/错误即时高亮（瞬时反馈）。
- 显示本局进度（第 N/总题量）与已用题量。
- 解析默认收起，可展开查看；解析含考点标签（数据来自票 06）。
- 多选题呈现四态（已选且正确 / 已选但错误 / 未选但正确（漏选）/ 未选且错误）。
- 题目卡片固定展示 AIGC 标识位（Implementation 28）。
- 弱网或退出时界面不白屏，可继续作答已拉取题目（与票 07 协作）。
