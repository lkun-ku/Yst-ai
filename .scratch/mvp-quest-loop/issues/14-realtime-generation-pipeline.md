# 14 实时生成管线接入

## 概述
接入 ADR-0002 实时生成能力：错题即时变式（优先同考点备用题，池空才实时）、复盘报告个性化段落（模型只写个性化部分）；模型客户端封装作为唯一 AI 出口并提供可替换假实现（接缝 B）；每人每日实时上限 3 次；池化率 ≥95% 硬约束与超限自动降级；闲时批量生成扩充池至 1 万级。

## 范围
- in：模型客户端封装（接缝 B 假实现）、错题变式触发逻辑、复盘个性化段落、每日实时上限 3 次与降级、池化率监控与告警、闲时批量生成脚本。
- out：RAG 知识库上传（Should，推迟）、原题生成。

## 依赖（Blocked by）
- 04、08、09

## 验收标准（Acceptance Criteria）
- 错题变式优先取同考点备用题，池空才触发实时生成（Implementation 13）。
- 每人每日实时生成上限 3 次，超出降级为纯池化供给（考生无感，Implementation 14）。
- 复盘个性化段落由模型写，缺失时优雅降级（与票 08 协同）。
- 模型调用统一收口在客户端封装，测试用假实现，**不消耗 API 额度**（测试决策 33、45）。
- 实时生成占比 >5% 触发告警；超限自动降级纯池化（Implementation 17）。
- 闲时批量生成脚本可扩充题目池（目标 1 万级，ADR-0002 后果）。

- 测试决策 33（接缝 B）、38（供给与降级）。
