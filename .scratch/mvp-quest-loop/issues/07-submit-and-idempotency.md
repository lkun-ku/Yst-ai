# 07: 提交闯关局与幂等

**Labels:** ready-for-agent

**What to build:**

答完统一提交，服务端判定每题、生成复盘报告、更新掌握度、归集错题；同一闯关局重复提交返回首次结果，不产生第二份报告（用户故事 50、实现决策 5）。

- 入参为闯关局标识与作答序列；出参含每题判定结果、解析、复盘报告、掌握度增量、新增错题（实现决策 5）。
- 幂等：同一闯关局重复提交返回首次结果（用户故事 50）。
- 提交后闯关局锁定不可再改（实现决策 26 提交状态）。
- 提交过程出错有明确提示而非白屏（用户故事 51）。

**Blocked by:** 06 — 作答判定与即时解析

**Status:** ready-for-agent

**验收清单：**

- [ ] 提交后返回每题判定、复盘报告、掌握度增量、新增错题
- [ ] 同一闯关局重复提交返回首次结果，不生成第二份报告
- [ ] 提交后闯关局锁定不可再改
- [ ] 提交失败有清晰错误提示
