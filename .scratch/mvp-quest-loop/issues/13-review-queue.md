# 13: 审校最小能力与题目纠错

**Labels:** ready-for-agent

**What to build:**

题目进入题库前必经「生成 → 结构化校验 → 人工抽检 → 入池」（实现决策 18–20）；提供最小审校能力（待审队列、通过 / 驳回、错误报告处理，spec 范围外清单）；考生可提交题目错误（答案错 / 解析错 / 考点归属错）进入审校队列（用户故事 21–22、实现决策 11）。

- 结构化校验：schema、答案唯一、选项互斥、解析非空、考点归属存在（实现决策 19、测试决策 44）。
- 抽检比例按模块差异化，文化素养最高（常识 / 历史 / 科技最易出错）（实现决策 20）。
- 不通过或存疑即弃，不入库。
- 考生纠错入口 → 审校队列（用户故事 21–22）。

**Blocked by:** 12 — 大模型客户端封装与出题管线（接缝 B）

**Status:** ready-for-agent

**验收清单：**

- [ ] 题目入库前必经结构化校验，不合格即弃
- [ ] 校验覆盖 schema / 答案唯一 / 选项互斥 / 解析非空 / 考点归属
- [ ] 抽检比例按模块差异化，文化素养最高
- [ ] 考生可提交三类错误，进入审校队列并被处理
- [ ] 提供最小审校能力：待审队列、通过 / 驳回、纠错处理
- [ ] 不违背 ADR-0003（以考纲为骨架自研，不存原题原文）
