# 06 答题判定与逐题解析

## 概述
实现「提交闯关局」接口（幂等）与逐题判定：单选/多选四态输出；解析含考点标签；错误反馈含正向成分；提供「报告题目错误」入口数据（进入审校队列，票 13）。

## 范围
- in：提交闯关局接口、逐题判定（四态）、幂等、解析与考点标签返回、正向反馈数据、纠错入口数据（错误类型：答案/解析/考点归属）。
- out：复盘报告生成（票 08）、审校队列后台（票 13）。

## 依赖（Blocked by）
- 03

## 验收标准（Acceptance Criteria）
- 提交返回每题判定结果（四态）、解析、考点归属。
- 提交**幂等**：同一闯关局重复提交返回首次结果，不生成第二份报告（Implementation 5）。
- 多选题四态输出正确（已选且正确 / 已选但错误 / 未选但正确（漏选）/ 未选且错误）。
- 错误反馈含正向成分（如本题错误率、连续答对计数）。
- 解析含考点标签。
- 「报告题目错误」入口提交错误类型（答案错误 / 解析错误 / 考点归属错误），数据进入审校队列（票 13）。
