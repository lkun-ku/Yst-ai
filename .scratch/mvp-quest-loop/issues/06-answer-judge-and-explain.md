# 06: 作答判定与即时解析

**Labels:** ready-for-agent

**What to build:**

选中选项即时高亮对错，再展开解析与考点标签；多选题区分四种状态（已选正确 / 已选错误 / 漏选 / 未选且错误），消除「我没错为什么扣分」的困惑（用户故事 16–20、实现决策 22/23/24）。

- 选中即瞬时判定对错（用户故事 16）。
- 展开后显示正确答案与解析，并标注考点（用户故事 17、19）。
- 多选题解析呈现四态（实现决策 22）。
- 错误反馈包含正向成分（如该题错误率、连续答对计数），避免纯负反馈（实现决策 24、用户故事 20）。
