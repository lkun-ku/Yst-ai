# MVP 规格：教资《综合素质》客观题闯关闭环

> Feature slug：`mvp-quest-loop`
> 创建时间：2026-05-21
> 综合来源：[需求分析文档](../../docs/需求分析文档.md) ｜ [竞品调研报告](../../docs/竞品调研报告.md) ｜ [术语表](../../CONTEXT.md) ｜ [ADR-0001~0004](../../docs/adr/)
> 数值来源分级：【官方】【一手】【二手】【估算】

## Problem Statement

从考生的视角，备考教师资格证《综合素质》时有五个真实困境：

1. **不知道自己哪里不会。** 现有工具只给正确率，不给考点维度的诊断，考生只能盲目全刷，时间花在不该花的地方。
2. **错题看了就忘。** 错题本只是一个列表，不会主动安排复习，同样的考点反复错。
3. **免费产品套路多。** 免费内容往往只有两三成，核心卷种与试卷被会员墙锁住，刷题过程还插广告；换设备后学习记录清零。
4. **碎片时间难以坚持。** 备考期 2-3 个月，每天只有课间、通勤、睡前等 5-15 分钟，缺少明确且轻量的每日目标。
5. **对题目质量没有信心。** 考生对错误答案零容忍——一道错题就足以让人弃用整个产品。

本 MVP 聚焦其中可解且可验证的部分：**客观题训练**（《综合素质》卷面 150 分中单选题占 58 分【二手】）。

## Solution

一款微信小程序，把客观题训练做成一次完整的闯关闭环：

- **进入即用**：允许游客先玩一局再授权，不把登录挡在价值之前。
- **轻量开局**：按模块或考点发起一次**闯关局**，固定 10 题，一次拉取并本地缓存，答完统一提交。全程约 2 分钟，弱网可续答，退出不丢进度。
- **即时讲解**：选中即高亮对错，再展开解析与考点标签；多选题区分「已选正确 / 已选错误 / 漏选 / 未选且错误」四种状态，消除「我没错为什么扣分」的困惑。
- **有诊断的报告**：闯关结束生成**复盘报告**——掌握度、3 个薄弱考点、以及「下一步只做一件事」，不堆砌数据。
- **错题会回来**：答错的题按考点聚合进**错题本**，并自动进入次日的**每日任务**；任务以考期倒计时为锚，当日有效时限 12 小时。
- **看得见的方向**：**掌握度**以五维雷达呈现，维度与官方模块权重一致（职业理念 15%、职业道德 15%、教育法律法规 10%、文化素养 12%、基本能力 48%【二手】），让考生知道时间该花在哪。
- **干净的免费体验**：免费考生每日 20 题，**全部模块与考点永远可刷**，只对题量限速，不对内容设限——这是与「免费 20-30%、核心上锁」的机构产品最大的差异。
- **可信任的质量**：题目以官方考纲与考点体系为骨架生成**变式题**，经结构化校验与人工抽检后入库；所有 AI 生成内容显式标识，并提供纠错入口。

## User Stories

### 进入与身份

1. As a 首次打开小程序的考生, I want to 不登录就先完成一局闯关, so that 我能在付出任何个人信息之前判断这个产品值不值得用
2. As a 游客, I want to 在体验完一局后再决定是否授权微信登录, so that 我的学习记录可以从这一刻开始被保存
3. As a 考生, I want to 用微信静默登录, so that 我不必输入手机号或密码就能拥有账号
4. As a 已授权的考生, I want 我的身份在更换 AppID 后仍可识别, so that 主体升级为个体工商户时我的学习记录不会全部作废
5. As a 考生, I want to 在首次使用时看到一次 AI 生成内容的说明, so that 我知道题目由 AI 生成且仅供参考，且这个提示不会反复打扰我
6. As a 考生, I want to 随时查看并删除我的学习数据, so that 我对自己的数据有控制权

### 发起闯关与答题

7. As a 考生, I want to 按模块发起一次闯关局, so that 我能针对最弱的模块集中训练
8. As a 考生, I want to 按具体考点发起闯关, so that 我能精准补某一个知识点
9. As a 考生, I want 一局固定 10 题, so that 我能用碎片时间完成，不会因为题量太大而放弃
10. As a 考生, I want 题目在一局内不重复出现, so that 我不会在同一局里刷到重复的题
11. As a 考生, I want 一局内不出现连续两个相同题型, so that 答题过程不会因重复而枯燥
12. As a 考生, I want to 中途退出后重新打开还能接着答, so that 碎片时间被打断不会白费
13. As a 弱网环境下的考生, I want to 在无网络时继续作答已拉取的题目, so that 地铁或电梯里也能刷题
14. As a 考生, I want 答题过程中不需要每答一题就等待网络, so that 答题节奏连贯不被打断
15. As a 考生, I want to 看到本局进度与已用题量, so that 我知道还剩多少题

### 即时反馈与解析

16. As a 考生, I want to 选中选项后立刻知道对错, so that 我不需要等到交卷才知道结果
17. As a 考生, I want to 看到正确答案与详细解析, so that 我不仅知道答案还知道为什么
18. As a 多选题答错的考生, I want 解析区分「我选错了」和「我漏选了」, so that 我不会误以为自己没错却被扣分
19. As a 考生, I want 解析中标注本题所属考点, so that 我知道这道题在考什么
20. As a 答错的考生, I want 解析中给出正向反馈而非单纯否定, so that 我不会因为连续答错而失去动力
21. As a 考生, I want to 对有疑问的题目提交纠错, so that 错误题目能被修正而不是继续误导他人
22. As a 考生, I want to 报告一道题的错误（答案错误、解析错误、考点归属错误）, so that 题目质量有外部监督

### 复盘报告与掌握度

23. As a 完成一局的考生, I want to 拿到一份复盘报告, so that 我知道这一局的收获而不是只看到一个分数
24. As a 考生, I want 报告中给出掌握度, so that 我能量化自己的水平
25. As a 考生, I want 报告指出我最薄弱的 3 个考点, so that 我知道下一步该练什么
26. As a 考生, I want 报告只告诉我「下一步做一件事」, so that 我不会被一堆建议淹没
27. As a 考生, I want 掌握度按五个模块分维度呈现, so that 我能看到自己在考纲各部分的真实水平
28. As a 考生, I want 掌握度维度与官方模块权重一致, so that 我能据此判断时间投入的优先级
29. As a 长期使用本产品的考生, I want 掌握度随我的答题历史持续更新, so that 它能反映我的真实进步
30. As a 考生, I want 明确知道报告由 AI 生成且仅供参考, so that 我不会把它当成官方评分标准

### 错题本与每日任务

31. As a 考生, I want 答错的题自动进入错题本, so that 我不需要手动记录
32. As a 考生, I want 错题按考点聚合而非堆成流水账, so that 我能看出自己在哪些考点上反复出错
33. As a 考生, I want 从错题本直接发起针对该考点的重练, so that 错题能被真正消化
34. As a 考生, I want 系统把错题自动排进后续的每日任务, so that 我不需要自己规划复习
35. As a 考生, I want to 输入考期后看到倒计时, so that 我有明确的时间压力感
36. As a 考生, I want to 每天看到当天的学习任务, so that 我知道今天该做什么而不必自己决策
37. As a 考生, I want 每日任务在当日有效时限内完成才算, so that 我每天都有回来的理由
38. As a 考生, I want to 完成每日任务后看到明确的完成反馈, so that 我有成就感

### 额度与 VIP

39. As a 免费考生, I want 每天能免费刷 20 题, so that 日常保持手感足够用
40. As a 免费考生, I want 所有模块和考点都能刷到, so that 我不必为了学某个模块而被迫付费
41. As a 免费考生, I want to 清楚看到今天还剩多少题, so that 我能自己安排什么时候用
42. As a 额度用尽的考生, I want 看到友好的额度提示而不是弹窗强推付费, so that 我不会因为被硬拦而流失
43. As a VIP 考生, I want 不限题量地刷题, so that 冲刺期可以大量训练
44. As a VIP 考生, I want 获得深度复盘报告, so that 我能得到个性化的学习建议
45. As a 考生, I want to 清楚看到 VIP 与免费版的区别, so that 我能自主判断值不值得买

### 内容安全与合规

46. As a 考生, I want 我输入的任何文本都经过内容安全检测, so that 平台不会因为不当内容被处罚
47. As a 考生, I want 看到的每道 AI 生成题目都有明确标识, so that 我知道内容来源
48. As a 考生, I want 在提交自由文本时看到输入限制说明, so that 我知道什么能填什么不能填
49. As a 考生, I want 违规内容被拦截时得到清晰提示, so that 我不会困惑于「为什么提交失败」

### 可靠性

50. As a 考生, I want 重复提交同一局不会产生重复结果, so that 网络抖动不会让我拿到两份报告
51. As a 考生, I want 答题过程中出现错误时有明确提示而非白屏, so that 我知道该重试还是放弃
52. As a 考生, I want 题目供给在成本超限时优雅降级而不是直接不可用, so that 我仍能继续刷题

## Implementation Decisions

### 架构与模块

1. **分层**：小程序前端（Taro 4 + Vue 3 + TypeScript + NutUI + Pinia，**仅微信单端**，遵守 ADR-0004）↔ 后端 API 服务（Python 3.11 + FastAPI）↔ 数据层（MySQL + 向量库）。后端内部划分为：闯关服务、题目供给服务、审校管线、复盘服务、内容安全适配、大模型客户端封装。
2. **小程序与后端之间只有 HTTP API 一个契约面**。所有考生可见行为（出题、判定、解析、复盘、错题、每日任务、额度、VIP 权限）都通过该面表达，便于把 API 边界作为主测试接缝。
3. **大模型调用统一收口在服务层的客户端封装**，不散落在各处。这是唯一的 AI 出口，用于替换假实现、统计调用量、执行降级（见下）。

### 接口契约（语义，不含路径与代码）

4. **开始闯关局**：入参为模块（或考点）与题量；出参包含闯关局标识、题目集合（每道题含题干、选项、正确答案、解析、考点归属、AIGC 标识、来源标识）、以及本局的题序。**一局的全部题目一次下发**，作答期间不再请求网络。
5. **提交闯关局**：入参为闯关局标识与作答序列；出参包含每题判定结果、解析、复盘报告、掌握度增量、新增错题。**提交必须幂等**——同一闯关局重复提交返回首次结果，不产生第二份报告。
6. **续答**：闯关局的题目与作答状态在客户端持久化；未提交的闯关局在重新打开时可恢复。服务端以闯关局标识为准，允许重复拉取同一局的题目。
7. **获取每日任务**：出参为当日任务清单（含考期倒计时、任务完成状态、有效时限）与完成反馈。
8. **获取错题本**：按考点聚合返回，支持直接以某考点发起重练。
9. **获取掌握度**：返回五个模块维度的掌握度，维度与官方模块权重一致。
10. **获取历史闯关局**：返回列表，可回看任意一局的复盘报告。
11. **报告题目错误**：入参为题目标识与错误类型（答案错误 / 解析错误 / 考点归属错误），进入审校队列。

### 题目供给（遵守 ADR-0002）

12. **离线题目池为主供给，实时生成为辅**。池化率 ≥95% 为硬约束；实时生成调用占比超过 5% 即触发告警。
13. **实时生成的唯一触发点**：错题即时变式与复盘报告的个性化段落。错题变式**优先从同考点备用题取**，池空才触发实时生成。
14. **每人每日实时生成上限 3 次**，超出后降级为纯池化供给（考生无感，只是不再生成新变式）。
15. **复盘报告模板化**：固定结构由代码生成，模型只写个性化段落。
16. **闲时批量生成**：利用峰谷分时计价的闲时窗口扩充离线题目池。
17. **日级成本告警 + 自动降级**：实时生成调用量超阈值时自动切换为纯池化供给，保证服务可用。

### 出题与审校管线（遵守 ADR-0003）

18. **骨架来源**：官方考纲与考点体系。**不存储、不展示原题原文**；原题仅作为考频与考点分布的分析对象。
19. **生成 → 结构化校验 → 人工抽检 → 入池**。结构化校验包含：输出符合 schema、正确答案唯一、选项互斥、解析非空、考点归属存在。
20. **抽检比例按模块差异化**：文化素养最高（常识/历史/科技最易出错），教育法律法规次之，其余按标准比例。校验不通过或存疑即弃，不入库。
21. **题目实体需携带**：考点归属、来源标识（池化/实时）、审校状态、AIGC 标识位、版本号。

### 判定与展示

22. **题型支持单选与多选**（判断归入单选处理）。多选题解析必须呈现四态：已选且正确、已选但错误、未选但正确（漏选）、未选且错误。
23. **两段式反馈**：先高亮对错（瞬时），再展开解析（可延迟展开）。
24. **错误反馈必须包含正向成分**（如该题的错误率、连续答对计数），避免错题页成为纯负反馈现场。

### 数据决策

25. **考生身份主键使用 unionid 而非 openid**，并把小程序绑定到微信开放平台账号——为 ADR-0001 中「个人主体转个体工商户、更换 AppID」做准备。（⚠️ 待验证：不同主体的小程序能否绑定同一开放平台账号，需在注册个体工商户时实测。）
26. **闯关局记录**需包含：局标识、考生标识、题目序列、作答状态、提交状态、开始与提交时间——用于续答、幂等与历史回看。
27. **掌握度按模块维度存储**并随答题历史更新，维度固定为五个官方模块。

### 合规（遵守 ADR-0001）

28. **AIGC 显式标识**：题目卡片或解析区固定展示；复盘报告明确标注并附「AI 生成内容仅供参考」；首次使用时说明一次。
29. **内容安全**：考生输入侧与生成内容输出侧均需检测，未通过不得展示或入库。
30. **严禁诱导分享**：任何权益（补签、题量、解锁）都不得与分享行为绑定；分享只能是无权益挂钩的自愿行为。
31. **额度**：免费考生每日 20 题，跨局累计；VIP 不限。额度只对题量限速，不对内容范围设限。

## Testing Decisions

### 测试接缝（2 个）

32. **接缝 A（主，最高层）：后端 HTTP API 边界。** 小程序与后端之间只有这一个契约面，闯关局生命周期、判定、解析、复盘、错题、每日任务、额度与 VIP 权限全部可通过请求/响应验证。
33. **接缝 B（新增，必要）：服务层的大模型客户端封装。** 模型输出不确定且按量计费（预算 ≤300 元/月【已确认】），若不在这一层提供可替换的假实现，测试既不可重复又要消耗额度。选在服务层而非框架内部，是能选的最高位置。

> 为什么不是理想的 1 个：只留 API 接缝，则要么测试直接打真实模型（不可重复、烧钱），要么把替身埋进编排框架内部（接缝过低、随框架升级而碎裂）。

### 好测试的标准

34. **只测外部行为**：给定请求，断言响应与可观测状态变化。
35. **不测实现细节**：不测提示词内容、不测编排框架的内部调用顺序、不测数据库表结构细节、不测前端组件内部状态。
36. **每个测试都要能回答「考生会因此看到什么不同」**；不能回答的测试不写。

### 待测模块

37. **闯关局生命周期**：发起、续答、重复提交幂等、弱网续答、提交后不可再改。
38. **题目供给与降级**：池化命中、池空触发实时生成、每日实时生成上限、成本超限自动降级。
39. **答题判定与四态**：单选判定、多选漏选与错选的四种状态输出正确。
40. **复盘报告**：掌握度计算、薄弱考点选取（3 个）、「下一步一件事」生成、模板化结构完整。
41. **错题本与每日任务**：按考点聚合、进入次日任务、倒计时与任务时限。
42. **额度与 VIP 权限**：每日 20 题跨局累计、用尽后拦截、VIP 不限量。
43. **内容安全与 AIGC 标识**：输入拦截、输出拦截、标识位必现。
44. **审校管线的结构化校验**：schema、答案唯一、选项互斥、解析非空、考点归属；不通过即弃。

### 工程约定

45. 后端测试使用 pytest，通过接缝 B 的假实现隔离模型调用，**测试不消耗任何 API 额度**。
46. **MVP 期不做端到端 UI 自动化**（成本不划算）；关键路径（首次进入 → 一局完整闯关 → 报告 → 次日任务）以手工验收清单覆盖。
47. 本仓库尚无代码，无既有测试先例；上述约定即为初始基线。

## Out of Scope

本 MVP（2026-12 上线版本）**不做**以下事项：

**已明确砍掉的需求**

- AI 生图
- 联网搜索出题
- B 端企业培训
- 泛知识自由输入（任意主题出题）

## Further Notes

### 三个必须记住的产品事实

1. **客观题只占卷面 39%**：《综合素质》150 分中单选 58 分、材料分析 42 分、写作 50 分【二手】。MVP 覆盖的只是单选部分；写作单项 50 分是整卷最大一题，也是机构做得最敷衍的部分——这是 V1.1/V1.2 的核心付费理由，不是本 MVP 的事。
2. **竞品护城河是题量，痛点是信任**：题量打不过机构，但可以打赢「解析质量 + 智能复盘 + 干净体验」。免费额度按题量限速而非按内容上锁，就是这个判断的直接产物。
3. **题目质量是生命线**：考生对错误答案零容忍。结构化校验与人工抽检不是可选项，文化素养模块的抽检比例必须最高。

### 三个残余张力（已在需求分析文档中显式记录）

- 预算 ≤300 元/月 ↔ 实时 AI 出题 → 由 ADR-0002 的池化率硬约束化解
- 师范生付费能力弱 ↔ VIP 订阅变现 → 转化窗口集中在考前 1 个月，客单价定在冲动消费区间
- 文化素养模块最易出错 → 最高抽检比例、只出确定性高的事实题、存疑即弃
