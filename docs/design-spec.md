# 「纸卷」设计规范 v1.0（design-taste-frontend 方向 A 固化）

> 方向锚点：纸质试卷的留白感 × Apple 钱包的层级 × 多邻国的反馈节奏（去掉卡通）。
> 技术载体：微信小程序（WXML/WXSS/rpx）。来源：概念图 `ui-concepts/a-paper/` 三屏 + 用户确认（方向 A / 墨蓝 / 赤红 / 列表式首页）。
> 标准来源：design-taste-frontend（方向与禁忌）+ high-end-visual-design（留白尺度、动效曲线、按压物理）+ gpt-taste（字重对比、禁凑数文案、对比度纪律）。Web 专属项（GSAP/Tailwind/自定义字体/暗色模式）已按小程序载体裁剪，见各节说明。

---

## 1. 设计原则（四条，冲突时按序裁决）

1. **内容是主角**：题干、数字、复盘文字是界面唯一的视觉重心，界面退后。
2. **层级靠留白与字重，不靠卡片与阴影**：能用一条发丝线解决的，绝不加一个框。
3. **色彩吝啬**：全页只有墨蓝（行动/正确/进度）与赤红（错误）两种彩色，其余全是暖灰阶。
4. **安静**：无渐变、无发光、无玻璃、无 emoji 图标、无凑数文案。

## 2. 色彩

### 2.1 彩色（仅此两种，各司其职）

| 语义 | 值 | 允许用途 | 禁止用途 |
|---|---|---|---|
| 主色·墨蓝 | `#2F5A8F` | 主按钮底、选中态、正确反馈、进度填充、关键数字 | 大面积背景、标题文字、装饰 |
| 强调·赤红 | `#C25450` | 错误反馈、错误计数、「错 N 次」标记 | 任何非错误场景 |

**一致性锁**：一屏之内主色出现的位置 ≤ 4 处（按钮 + 进度 + 选中 + 至多一个关键数字）。赤红在一屏内只允许出现在错误语义上。

### 2.2 暖调灰阶（9 级 + 纸底）

| 级 | 值 | 用途 |
|---|---|---|
| paper | `#FAF7F2` | 页面底色（所有页面统一） |
| ink-50 | `#F3EFE7` | 区块底、选中行底、骨架屏 |
| ink-100 | `#EDE8DE` | 输入框底、代码/引用底 |
| ink-200 | `#E8E2D8` | **发丝线（唯一分割线色）**、未填充进度轨道 |
| ink-300 | `#D8D1C4` | 禁用态边框、进度轨道描边 |
| ink-400 | `#B8B0A2` | 占位文字、最弱辅助 |
| ink-500 | `#8A8577` | 次级文字、时间戳、说明 |
| ink-700 | `#55524A` | 正文次级、选项未选中文字 |
| ink-900 | `#1C1C1A` | 标题、题干、正文主色、数字 |

规则：文字只用 ink-900 / ink-700 / ink-500 三级；ink-400 及以下只用于占位与禁用。**禁止纯黑 `#000` 与纯白 `#FFF` 大面积使用**（白仅作为按钮反白文字）。

### 2.3 明确禁止

紫蓝渐变、多彩渐变、渐变按钮、渐变进度条；玻璃拟态/毛玻璃；发光与外阴影；多彩图标底；纯黑/纯白大面积。

## 3. 字体（系统字体栈 + 字重对比实现高级感）

小程序无法内置 Geist 等品牌字体（包体积与加载限制），高级感由**字号 5 级 + 字重对比 + 行高**实现：

| 级 | rpx | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| D1 | 44 | 700 | 1.3 | 题干、超大数字（倒计时天数、8/10） |
| T1 | 34 | 600 | 1.4 | 页面标题、区块标题、复盘段落首句 |
| T2 | 30 | 600 | 1.4 | 卡内标题、选项文字（加粗态） |
| B1 | 26 | 400 | 1.6 | 正文、选项常规态、解析 |
| C1 | 22 | 400 | 1.5 | 辅助说明、时间戳、标签 |

规则：
- 一屏内 D1 最多 1 处（题干 或 大数字，二选一）。
- 字重只用 400 / 600 / 700 三档；**层级优先靠字重与灰阶，不靠加色**。
- 数字（进度、倒计时、8/10）可用 `font-variant-numeric: tabular-nums` 等宽数字。
- 解析长文用 B1 + ink-700，行高 1.6，不压行。

## 4. 圆角（唯一值）

**16rpx，全项目唯一圆角值**：卡片、按钮、输入框、选项行、弹层、tag、骨架屏全部 16rpx。tag 等小元素同样 16rpx（不做胶囊）。头像/图标底若出现，同样 16rpx。禁止出现第二 种圆角。

## 5. 间距（8rpx 栅格）

| 令牌 | 值 | 用途 |
|---|---|---|
| page-x | 32rpx | 所有页面左右边距（唯一） |
| s1 | 8rpx | 图标与文字、标签内 |
| s2 | 16rpx | 相关元素间（选项行内、按钮与说明） |
| s3 | 24rpx | 卡内边距（统一卡片 padding） |
| s4 | 32rpx | 区块内子分组间 |
| s5 | 48rpx | 区块之间 |
| s6 | 72rpx | 页面大分区（题干区与选项区之间、结果页 hero 与列表之间） |

规则：屏内垂直节奏 s4 → s5 → s6 逐级放大，越重要的分隔留白越大；禁止出现非 8 倍数的间距。

## 6. 分层与阴影（无阴影体系）

**全项目禁用 box-shadow。** 层级表达仅三手段：
1. **发丝线**：`1rpx solid var(--ink-200)`，用于列表行分隔与区块分界；
2. **底色阶**：paper 页底 → ink-50 区块 → ink-100 输入底，最多差一阶；
3. **留白**：s5/s6 的大间距本身就是最强分层。

卡片仅在「内容天然成组」时使用（如复盘 hero、题目卡），且必须带 s3 内边距 + 16rpx 圆角 + ink-200 描边（或 ink-50 底，二选一）。**同一屏卡片数量 ≤ 2**，其余内容一律平铺 + 发丝线。

## 7. 图标

- 统一**线性**风格，等效 stroke 1.5px，单色（ink-700 或主色，随语义）。
- 来源：Reicon（reicon-mcp）线性权重，禁 emoji、禁混用面性。
- 尺寸三档：40rpx（入口列表）、32rpx（行内操作）、24rpx（标签前缀）。
- 一屏图标 ≤ 6 个，图标是功能的路标不是装饰。

## 8. 组件规范

### 8.1 按钮

| 型 | 样式 |
|---|---|
| 主按钮 | 墨蓝底、白字 T2/600、16rpx 圆角、高 88rpx、全宽；按下 `scale(0.98)` |
| 次按钮 | 透明底、墨蓝字 + 墨蓝 1rpx 描边、同尺寸 |
| 幽灵行按钮 | 无框无边，ink-700 文字 + 24rpx 线性图标（如「重练」） |
| 危险 | 赤红字 + 赤红 1rpx 描边（仅删除/不可逆操作） |
| 禁用 | ink-50 底 + ink-400 字，无边框 |

按钮文案 ≤ 4 个汉字，单一意图；一屏同意图按钮只出现一次。

### 8.2 答题选项行（核心组件）

| 态 | 样式 |
|---|---|
| 默认 | 透明底，ink-200 发丝线下边线，字母圈 ink-300 描边 + ink-700 字母，文字 B1/ink-700 |
| 选中 | 底 ink-50，字母圈墨蓝实心白字，文字 T2/ink-900/600 |
| 正确 | 字母圈墨蓝实心，行尾 24rpx 线性对勾（墨蓝），无底色变化 |
| 错误 | 字母圈赤红描边，行尾线性叉（赤红），选中的错误项文字 ink-900 |
| 禁用（已答） | 整行 ink-400，不可点 |

选项行高 ≥ 96rpx，多选项间只有发丝线（不包框）。

### 8.3 进度条

高 4rpx；轨道 ink-200；填充墨蓝；圆角 2rpx；禁止渐变填充与百分比文字堆叠在条上（数字放条外）。

### 8.4 输入框（填空/简答/搜索）

ink-100 底、无边框、16rpx 圆角、高 88rpx（简答 textarea 240rpx 起）；聚焦态 1rpx 墨蓝描边；label 在输入框上方（C1/ink-500），错误提示在下方（C1/赤红）。禁止 placeholder 当 label。

### 8.5 状态三件套（每屏必备）

- **加载**：骨架屏（ink-50 色块 + 匹配最终布局的形状），禁转圈 spinner。
- **空态**：一行主文案（T2/ink-900）+ 一行说明（C1/ink-500）+ 幽灵行动按钮；不加插画。
- **错误**：行内赤红文字（表单）或整页错误卡（含「重试」次按钮）。

## 9. 动效（小程序裁剪版）

- **曲线**：`cubic-bezier(0.32, 0.72, 0, 1)`（唯一曲线）；时长 240ms（反馈）/ 400ms（进入）。
- **属性**：只动 `transform` 与 `opacity`；禁 linear/ease-in-out。
- **按压**：所有可点元素 `hover-class` 实现 `scale(0.98)`（等效 150ms）。
- **进入**：页面主区块 fade-up（`translateY(24rpx)→0` + opacity，400ms，可 60ms 级联）。
- **反馈节奏**（多邻国式）：答对——选项行墨蓝确认 + 底部按钮浮现；答错——错误项赤红 + 正确项墨蓝描边浮现；均 240ms。
- 小程序无 GSAP；上述全部用 WXSS transition/animation 实现，遵守 reduced-motion 语义（`wx.getSystemSetting` 无对应项，暂以短时长实现，二期再补）。

## 10. 文案纪律

- 按钮与动作 ≤ 4 字；同一屏同意图动作只出现一次。
- 禁凑数修饰（「极致」「丝滑」「赋能」）；说明文字直说功能。
- 空态文案给「下一步」而非抱怨（「还没有错题，继续保持」✓）。
- 禁 meta 标签（「模块 01」「第 2 区块」）。

## 11. 逐屏改版映射（第 3 步施工清单）

| # | 页面 | 改版要点 |
|---|---|---|
| 1 | index 首页 | 卡片堆叠 → 平铺分区（考期大数字区 / 进度区 / 任务行 / 入口列表）；五宫格彩底 → 发丝线列表 + 线性图标；渐变进度 → 4rpx 墨蓝条 |
| 2 | quest 闯关发起 | 模块选择 → 列表式考点选择（发丝线分组），主色仅落在「开始闯关」 |
| 3 | answer 答题 | 五层容器 → 题干 hero + 选项行列表；答题卡 → 底部弹层（sheet，ink-50 底）；对错反馈按 9 节节奏 |
| 4 | review 结果 | 五卡 → 报告平铺（hero 数字 / 五维条 / 薄弱行 / 段落）；卡片 ≤ 2 |
| 5 | history 历史 | 卡片列表 → 发丝线时间线行；重练按钮 → 幽灵行按钮 |
| 6 | mistakes 错题本 | 彩 tag 卡片 → 分组行列表 + 赤红计数；今日任务区保序 |
| 7 | docs 资料 | 上传主按钮降级为幽灵；卡片 → 行列表；改名/删除 → 行内幽灵按钮 |
| 8 | generate 出题表单 | 表单按 8.4 规范；容量提示行内化 |
| 9 | kb 组卷 | 同 generate 规范；时间线卡片去阴影 |
| 10 | doc-detail 详情 | 保持平铺 + 发丝线，全文展开态用 ink-50 底 |
| 11 | settings 设置 | 分组行列表（系统设置式），发丝线分组 |

每屏交付时附「本屏改动点与理由」说明；全部用真实题目内容排版（用户提供样例题，或取 dev.db 真实题）。

## 12. 验收（Pre-Flight，每屏过一遍）

- [ ] 全屏只有墨蓝 + 赤红两种彩色，主色 ≤ 4 处
- [ ] 圆角全部 16rpx；间距全部 8 的倍数；左右边距 32rpx
- [ ] 零 box-shadow、零渐变、零 emoji 图标
- [ ] D1 字号一屏 ≤ 1 处；字重只用 400/600/700
- [ ] 按钮/选项对比度 ≥ 4.5:1；无白字白底
- [ ] 加载/空态/错误三态齐备
- [ ] 同意图按钮唯一；文案 ≤ 4 字；无凑数修饰
- [ ] 动效仅 transform/opacity，曲线 0.32,0.72,0,1
