# 主观题批改（rubric-grounded）：语料边界、自定维度与拒批红线

## Status

accepted（2026-06-11）

> 上游：[ADR-0014](./0014-引用校验用子串硬匹配.md)（引用硬校验，本项直接复用）、
> [ADR-0013](./0013-官方语料命名空间隔离.md)（语料与权限边界）。
> 范围依据：`docs/改造计划.md` §3 第 9 项。

## Context

科目一（综合素质）的材料分析题 **42 分** + 写作题 **50 分** = 卷面 **61%**，
而市面产品几乎只做客观题。"会背不会写"是跨考生最真实的痛点。
技术上这是 **RAG for Evaluation** —— QA / Generation / Evaluation 三形态里最稀有的一种。

开工前先查了一个前置事实，结果改变了本项的做法：

| 检查 | 结果 |
| --- | --- |
| `domain_packs/k1_comprehensive/` | **只有 `pack.yaml`** —— 没有 `rubrics/`、没有 `syllabus/` |
| `data/official/` | 只有 `laws/`、`regulations/`（6 部法条） |
| 官方大纲正文 | 官方只提供 `.doc` 附件（二进制、中文乱码，**本环境无法解析**）；HTML 页只有下载链接 |
| 主观题官方评分细则 | **从未公开发布** —— 流传版本来自培训机构，非官方且有版权 |

结论：**"rubric-grounded" 没有 rubric 可检**。若照原计划直接做批改，
检索回来的"依据"会是**无关的法条** —— 那比不检索更糟：它让考生以为意见有出处。

## Decision

### 1. 先补语料，且语料里**只放可引用的官方原文**

本轮入库了能从官方渠道取得的《中小学教师职业道德规范（2008年修订）》
（教师〔2008〕2 号，教育部官网 HTML）+ 已入库的 6 部教育法条。
批改依据 = 这两类**可引用文本**。

**⚠️ 语料里不放"说明性文字"** —— 这条是踩出来的：
第一版把「关于语料性质的声明」（它含"材料分析题""采分点""评价"等词）
写进了正文，结果 `retrieve_rubric` 把它排在了**第一位**，
真正的采分点（关爱学生 / 教书育人）反而排在后面 —— **说明文字变成了检索噪音**。
修正：语料文件只保留官方原文，说明放 ADR 与代码注释，frontmatter 里留一行 `note`。

### 2. 四维度是**产品自定**的，必须随结果一起声明

`切题度 / 论据 / 结构 / 语言` 是**我们定义的**结构化反馈维度。
官方从未公布过这样的划分。因此：

- API 响应里带 `dimensions_disclaimer`：「四维度为本产品自定的结构化反馈口径，非官方评分维度」；
- 文档与代码注释里反复申明同一件事。

**把自定维度说成官方口径，就变成了编造** —— 那正是本产品最不能犯的错。

### 3. 两条**硬**规则（与出题链路的引用校验同一哲学）

1. **没有依据就不批**：`rubric` 为空 → 直接拒批（而不是给一个"感觉分"）；
2. **引用必须能定位**：任一 `quote` 无法在依据里逐字找到 → 整条批改转拒批。
   "句句有出处"不能因为"其余都对"而打折。

复用 `citation.split_by_citation` —— 与出题、问答链路**同一个判定**，
不搞第二套实现（第二套实现就意味着第二套漂移）。

### 4. 依据由**题型**检索，不用考生答案

`RUBRIC_QUERY[qtype]` 决定检索词，`retrieve_rubric(db, scope, qtype)` 签名里**没有答案参数**。
理由：用答案去检索，就是按答案内容去找"支持它的依据" —— **确认偏误的机器版**。

### 5. 一致性度量单列端点，且拒批**不计入**标准差

`POST /api/marking/consistency` 独立于 `evaluate`：
它是"给 AI 批改不可信一个数字"的**测量**动作，挂在默认路径上会让每次批改都三倍成本。

两条口径纪律：

- **只统计成功的批改次数**：否则"拒批"会被当成"分数为 0"，
  把一个"依据不足"的问题伪装成"打分不稳"（两者的修法完全不同）；
- **全部拒批时返回 `n=0`**，路由层转 409/503 —— 不返回一个看起来像"很稳"的 0。

## Considered Options

- **直接做批改、先不管语料**（否决）：依据会是无关法条，"有据"变成空话。
- **用培训机构的"评分标准"**（否决）：非官方来源 + 版权风险，
  且与产品"句句有出处"的主张直接冲突。
- **把四维度包装成官方口径**（否决）：编造。
- **把说明文字放进语料**（**实测否决**）：它成了检索噪音，挤掉了真正的采分点。
- **无依据时给"感觉分"**（否决）：考生无法分辨哪条意见有出处。
- **把一致性度量挂在 evaluate 上**（否决）：每次批改三倍成本。
- **把拒批计入标准差**（否决）：把依据问题伪装成稳定性问题。

## Consequences

- **产品多了一条覆盖 61% 卷面的能力**，且它与出题、问答共用同一套检索、引用校验、
  命名空间隔离 —— 没有第二套实现，也就没有第二套漂移。
- **语料**：7 份文档 / **421 片**（415 法条 + 6 条职业道德规范）。
- **新增 18 个用例**（`tests/test_marking.py`），其中三条是红线：
  `test_没有依据就不批`、`test_引用了依据里找不到的原文就拒批`、
  `test_全部拒批时返回n为0而不是不一致`。
- **新增 2 个配置项**：`MARKING_VOTES`（默认 3）、`MARKING_RUBRIC_K`（默认 6）。
- 全量回归 **430 passed / 10 skipped**。

### 已知边界（记为未决，不假装已完成）

1. **官方大纲正文没拿到**：官方只有 `.doc` 附件（二进制、中文乱码，本环境无法解析），
   HTML 页只有下载链接。大纲里的**试卷结构与题型要求**属于可引用材料，待补齐
   —— 它比现在手上的"职业道德规范"更贴近"评分要求"。
2. **真实模型下的一致性目前无数据**：`LLM_MODE=fake` 时替身每次给同样的分，
   标准差**必然为 0** —— 那个 0 只是"替身很稳"，**不是**"批改很稳"的证据。
   必须用真实模型重跑才有意义。
3. **四维度没有与人工评分做过校准**：维度分数是否与阅卷老师的判断相关，未知。
   在拿到人工标注前，它只是"结构化反馈"，不是"分数预测"。
4. **只有职业道德规范一份 rubric 语料**：材料分析题的另一大类考点
   （学生观 / 教师观 / 教育观）在大纲里，而大纲没拿到；
   写作题的评分维度也没有对应语料。当前 rubric 覆盖是**部分的**。
5. **前端未做**：计划里的 `pages/subjective/` 未实现，本项只交付后端接口与度量。
6. **`Scope.subject` / `stage` 仍不参与 SQL 过滤**（ADR-0013 已记录），
   所以"按科目取 rubric"暂时只在语义上成立。

## 反转条件

1. **若拿到官方大纲**（或其 HTML 版本），应把它入库并重新设计 `RUBRIC_QUERY` ——
   大纲的题型要求比职业道德规范更贴近"评分要求"。
2. **若真实模型下的一致性标准差过大**（例如各维度 std > 10），
   应先收敛提示词与评分锚点，而不是取消一致性度量 ——
   它是这个功能能不能被信任的前提。
3. **若获得人工评分样本**（哪怕 50 份），应做维度分数与人工分的相关性检验；
   相关性过低时应重定义维度，而不是继续输出四个好看但无意义的分数。
4. **若未来把批改接进小程序**，必须把 `dimensions_disclaimer` 与
   "不承诺与官方评分一致"两条一起放进界面 —— 不能只留在 API 响应里。
