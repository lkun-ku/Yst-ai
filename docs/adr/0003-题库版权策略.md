# 题库版权策略：不存原题，以官方考纲与考点体系为骨架自研变式题

历年考试原题受著作权保护，未经许可的复制、传播、商业使用可能构成侵权（个人学习少量使用属合理使用的例外，不适用于本产品的商业场景）。我们决定：**不存储、不展示任何原题原文**，仅以官方发布的考试大纲与考点体系作为出题骨架，由 AI 生成变式题；原题只作为考频与考点分布的分析对象，不进题库。

## Status

accepted（2026-03-04）

## Considered Options

- **用公开的「考生回忆版」原题整理入库**（放弃）：行业普遍做法，风险低于直接复制真题，但回忆版质量参差、存在错误，且仍非无风险。
- **采购或与机构合作拿授权题库**（放弃）：最合规，但需要资金与商务谈判，早期不现实。
- **真题只做考点索引、题目全部自研**（部分采纳）：索引思路保留用于考频分析，但不作为题目来源。
- **以考纲为骨架自研变式题**（采用）：版权风险最低，题目可无限扩充。

## Consequences

- 产品**不能把「真题」作为卖点**。市场推广需转向「考点覆盖度」「解析质量」「智能复盘」「主观题批改」。
- 题目质量只能靠考纲对齐度、结构化校验与人工抽检保证，**不能靠与真题比对验证**——审校流程因此成为质量生命线。
- 考频热力图（亮点 L5）依赖外部公开统计或自行积累的作答数据，早期数据稀疏时该功能价值有限，故列为 Could。
- 用户通过 RAG 上传的资料，权属由用户自行负责，需在上传协议中明确，并保留删除能力。
