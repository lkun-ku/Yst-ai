# 引用校验用子串硬匹配，不用语义相似度或 LLM 判定

## Status

accepted（2026-06-11）

> 上游：[ADR-0003](./0003-题库版权策略.md)（内容来源合规）、
> [ADR-0013](./0013-官方语料命名空间隔离.md)（官方语料 `is_official`，引用校验的语料基础）。
> 范围依据：`docs/改造计划.md` §3 第 4 项。

## Context

产品定位里有四个字是硬承诺：**句句有出处**。它的失败面很窄但很致命 ——
法条类内容一旦编造（错条号、错主体、错表述），用户会据此作答并失分，
而产品**不会报错**：生成照常返回、界面照常渲染，用户无从察觉。

现有防线全部是概率性的：

| 防线 | 为什么不足以支撑"零编造" |
| --- | --- |
| 提示词约束 | 是请求不是保证；模型改写引用是**默认行为**，不是异常 |
| 生成自检（LLM judge） | 有成本、有随机性；同一输入两次可能给不同结论；**它自己也会幻觉** |
| 语义相似度 | 对**编号级篡改完全无感** —— "第七条"与"第八条"在同一部法里措辞高度接近，相似度能到 0.9+ |
| 人工抽检 | 无法覆盖全量，且不能作为"零"的证据 |

关键洞察是：**"是否编造"这个问题有一个布尔答案，不该用概率方法去猜它。**
一段引用要么能在给定切片里逐字找到，要么找不到 —— 这是字符串问题，不是语义问题。

## Decision

### 1. 强制 `source_quote` + 子串硬校验，判定分五个状态

`services/citation.py`，状态互斥且**分别计数**：

| 状态 | 判定 | 闸门行为 | 为什么单列 |
| --- | --- | --- | --- |
| `exact` | 原样子串命中 | 放行 | 证据最强 |
| `normalized` | 只比较汉字/字母/数字后命中 | 放行 | 容忍写法差异 |
| `fabricated` | 都不命中 | **总是拦截** | 真编造，产品的红线 |
| `too_short` | 归一化后长度不足 | **总是拦截** | 引用过弱，**不是编造** |
| `missing` | 没给引用 | 默认放行（`citation_require_quote` 可改） | 提示词遵守度问题 |

**`too_short` 与 `fabricated` 必须分开，这是本次的一条硬纪律**：
`第七条` 这种三字引用在原文里**逐字存在**，按真值定义它是真实引用。
把它记成"编造"会让"零编造"这个指标变得不诚实 —— 于是"引用太短"与"凭空捏造"
被算成一回事，数字好看但含义被污染。过短被拦的理由是另一条（不能作为证据），
所以它有独立的状态与计数。

### 2. 剥书名号前缀，但**条号必须参与比对**

模型被要求"给出处"时最自然的写法是 `《教师法》第七条：原文`，
其中 `《教师法》` 是**元数据**（切片正文里没有，只在 `heading_path` 里）——
不剥会把一批**真实引用**误判为编造，而误判的方向恰好是我们要避免的。

但**条号绝不能剥**：若剥掉 `第X条`，那么
`《教师法》第九十九条 + 第七条的正文` 这种**错配**就会通过校验 ——
而这正是引用校验最该抓的一类错误（正文对、出处错）。

### 3. 闸门位置：规则校验**之后**、LLM 自检**之前**

规则校验回答"格式对不对"，引用校验回答"有没有依据" ——
**两者都是确定性判定、零模型调用、零成本**。排在自检之前可以用最低代价砍掉最危险的一类输出；
若顺序反过来，会先花 LLM 调用去评估一道**依据根本不存在**的题 ——
既浪费额度，又让自检的结论不可信（它在评一道无据题"质量如何"）。

### 4. 闸门**不随** `enable_loop` 开关

它是确定性硬约束，不是"质量闭环"的一环。若只在 loop 路径加，
A/B 对照（loop vs 非 loop）就会混入第二个变量，实验结论不成立。

### 5. 假客户端必须摘**真实原文**作为引用

`FakeLLMClient` 从出题提示词的切片块里原样摘录一句。
若 fake 给的引用定位不到，`LLM_MODE=fake` 下**所有题都会被闸门拦掉**，
测试将再也覆盖不到闸门之后的链路 —— 等于把下游一起"测没了"。
没有切片可摘时返回"未给引用"，**不编一个来充数**。

### 6. 指标必须**成对**上报

`eval/metrics.py` 的 `CitationGateMetrics`：

| 指标 | 公式 | 回答什么 |
| --- | --- | --- |
| 拦截率 | 拦下的已知编造 / **已知编造总数** | 该拦的拦住了吗 |
| 流出编造率 | 流出且真值为编造 / **通过总数** | 出去的东西干净吗 |
| 误杀率 | 被拦的真实引用 / 真实引用总数 | 代价有多大 |

**只看"流出编造率 = 0"是自欺**：闸门未触发时它同样是 0，
一个**关掉的闸门**与一个**有效的闸门**在数字上完全一样。
所以 `sound` 的定义是「拦截率 > 0 **且** 流出编造率 = 0」。

### 7. 附带修复：章标题混入条文正文（由本次基准跑出来的真 bug）

`kb_corpus.split_law_articles` 取的是「本条开头 → 下一条开头」，而这两条之间
可能隔着**下一章的标题**（章的首条尤其常见）。原实现只切了条、没切章，
于是 `## 第二章 权利和义务` 成了第一章末条的**正文**。后果有两个：

1. 检索污染：章标题成了该片内容，会被向量与关键词通道一起命中；
2. **引用校验被绕过**：`source_quote` 可以引用一段章标题，
   而它会因为"确实出现在该片正文里"通过硬校验 —— 这是真实漏洞。

`_trim_trailing_chapter` 在切片期切掉它。这个 bug 不是靠读代码发现的，
是靠 `eval/citation_eval.py` 的一条用例漏放追出来的。

## Considered Options

- **语义相似度判定**（放弃）：对编号级篡改无感，而那是最致命的错误。
- **LLM judge 判定**（放弃）：不确定、有成本、自己会幻觉；用可能幻觉的组件校验幻觉只是挪走风险。
- **不剥书名号前缀**（放弃）：会把最自然的引用写法判为编造，误杀一批真实引用。
- **剥条号一并比对**（放弃）：会让"正文对、出处错"的错配通过 —— 恰好放过最该抓的错误。
- **把 `too_short` 记作 `fabricated`**（放弃）：见 Decision 1 —— 指标会变得不诚实。
- **闸门默认关闭，靠配置打开**（放弃）：红线不该是选项；开关只用于 A/B 对照。
- **只在 loop 路径加闸门**（放弃）：会让编排 A/B 实验混入第二个变量。

## Consequences

- **编造从"概率风险"变成"确定性拦截"**：不涉及任何模型调用，成本几乎为零，
  且在 LLM 自检之前就完成 —— 省掉的是**给无据题做质量评估**的那部分调用。
- **基准（`eval/results/citation_baseline.md`）**：378 条用例（正例 184 / 反例 194），
  拦截率 **1.0（194/194）**、流出编造率 **0.0（0/184）**、误杀率 **0.0**，成对达标。
  命中层级：逐字 49 / 归一化 135（**逐字占比 0.2663**）。
- **逐字占比 0.2663 是一个需要盯的信号**：它说明本组用例里多数命中靠归一化层。
  这在本组用例中是**构造使然**（正例刻意包含三类写法扰动），
  但它提示真实运行时也要看这个数 —— 若真实模型下偏低，说明提示词要收紧。
- **反例真值用「精确子串缺席」判定，不用校验器自己的归一化逻辑** ——
  否则等于让被测对象自己出考卷，漏放率恒为 0、测试失去意义。
- **新增 23 个用例**（`tests/test_citation.py`）+ 全量回归 **336 passed / 10 skipped**。

### 已知边界（记为未决，不假装已完成）

1. **概括与意译会被误杀。** 子串匹配的容忍范围只有"标点 / 空白 / 全半角 / 书名号"，
   模型若概括原文（"教师享有教育教学权" vs 原文"教师享有下列权利：进行教育教学活动…"）
   会被判为编造。这是**刻意选择的方向**（宁可误杀、不可漏放），但代价必须承认。
2. **误杀率 0.0 的含义有限。** 本组正例是四类**人工设计的**写法扰动，
   它只证明这些容忍度被完整覆盖，**不等于**真实场景零误杀。
3. **`source_quote` 目前只接在**出题**链路**（`kb_generate` 的 loop 与非 loop 两条分支）。
   问答老师（第 7 项）与主观题批改（第 9 项）的引用校验**尚未接入** ——
   那两条路径的输出形态不同（对话 / 批改意见），引用粒度需要另定。
4. **语料规模**：基准建在 415 片法条切片上，尚未覆盖考纲类语料
   （`domain_packs/*/syllabus/` 还没抓）。

## 反转条件

1. 若真实模型下的**误杀率超过 10%**（即提示词已尽力而模型仍普遍改写），
   应改为双轨：子串硬校验作为**主判**，再对未命中者做一次**受约束的**定位
   （例如只允许在检索到的切片内做编辑距离匹配，且必须命中到具体片、分数落到独立状态），
   而不是放宽子串判定的语义。
2. 若 `too_short` 拦下的**真实引用占比很高**（说明提示词要不到足够长的引用），
   应调 `citation_min_quote_chars` 或改写提示词要求"抄完整一句"，
   而不是取消这条策略。
3. 若官方语料扩展到**非条文类**（考纲 / rubric），需重跑基准 ——
   考纲是按段落切的，`source_quote` 的"一句"边界比法条模糊，误杀率可能上升。
4. 若需支撑"引用到**条**级并可跳转原文"，应把 `heading_path` 的解析结果
   （法名 / 章 / 条）提升为切片的**结构化元数据列**，而不是继续从字符串里解析。
