## 0. 本文档的定位与效力

| 项 | 内容 |
| --- | --- |
| 作用 | 定义「教资备考用户真正需要什么」，并作为路线排序的唯一依据 |
| 效力 | **本文与旧文档冲突时，以本文为准** |
| 可信度标注 | 【官方】考试院/政策原文；【二手】第三方评测；【估算】本文推算，已写明假设 |
| 校准方法 | 以官方备考指南的「六步备考建议」为骨架，逐条对照现有文档与开发任务的偏差（见 §5） |

### 校准的三条原则

1. **以官方口径为准绳** —— 科目设置、模块划分、分值、有效期一律以考试院信息为准，不以旧文档的习惯表述为准。
2. **以「用户能不能得分」排优先级** —— 分值权重 × 用户痛点密度决定顺序，不以技术难度或实现趣味决定。
3. **能不接 LLM 就不接** —— 凡规则引擎可实现的需求优先用规则实现（成本近零、结果确定）。

### 1.3 科目一《综合素质》五大模块【官方】

| 模块 | 主要内容 | 模块权重 |
| --- | --- | --- |
| 职业理念（教育观·学生观·教师观） | 素质教育内涵、"以人为本"学生观、新课改教师角色转变 | 15% |
| 教育法律法规 | 教育法/义务教育法/教师法/未成年人保护法/预防未成年人犯罪法/学生伤害事故处理办法；教师权利义务、依法执教 | 10% |
| 教师职业道德规范 | 爱国守法、爱岗敬业、关爱学生、教书育人、为人师表、终身学习 | 15% |
| 文化素养 | 历史、科技、传统文化、文学艺术常识；**范围广但考查较浅** | 12% |
| 基本能力 | 阅读理解、逻辑思维、信息处理、**写作**（通常为分值最大的一道题） | 48% |

### 1.4 科目一分值结构【二手】

| 题型 | 分值 | 占比 |
| --- | --- | --- |
| 单项选择题 | 58 分 | 39% |
| 材料（案例）分析题 | 42 分 | 28% |
| 写作题 | **50 分** | **33%** |
| **合计** | **150 分（卷面满分）** | 100% |

> **关键推论**：客观题仅覆盖 **39%** 卷面，且恰是机构题库最全、AI 最无优势的部分；
> **主观题（材料分析 42 + 写作 50）合计 92 分 = 61% 卷面**，才是真正的分差所在。
> 本推论是后续所有优先级排序的依据。

### 1.5 题型、时长与合格线【官方】

- 笔试每科 **120 分钟**；笔试卷面满分 150，折合为**报告分满分 120**，**报告分 70 分合格**；面试只报「合格/不合格」。
- 主观题题型：简答、论述、辨析、解答、材料（案例）分析、课例点评、诊断、**教学设计**、活动设计（幼儿园）、**写作**。
- 面试流程：抽题 → **备课 20 分钟** → 回答规定问题 → **试讲** → 答辩。

### 1.6 报考与认定规则【官方】

| 事项 | 规则 |
| --- | --- |
| 考试次数 | 每年上、下半年各一次 |
| 笔试成绩 | **单科有效期 2 年** |
| 面试报名 | 须笔试**全部科目合格**且成绩在有效期内 |
| 合格证明 | 笔面全合格后取得，**有效期 3 年** |
| 普通话 | 二乙及以上；语文、幼儿园等通常要求**二甲** |
| 音体美 | 须选报 **A 代码**（201A/202A/301A/302A）；**A 成绩不可替代普通代码，普通代码可替代 A** |
| 复习依据 | **以官方《考试大纲》和历年真题为核心材料** |

## 2. 用户是谁

按**身份轴**（为什么考）× **阶段轴**（考到哪一步）划分五类人群。占比为【估算】（官方不公布）。

| 编号 | 人群 | 学段倾向 | 特征 | 典型场景（真实、带口语） |
| --- | --- | --- | --- | --- |
| **A** | 非师范跨考 | 小学 / 初中 | 零基础、信息过载 | 晚上 11 点，出租屋。手机里存了 8 个备考公众号的收藏：「我完全不知道教资考什么，看了一周还在综合素质第一页。」 |
| **B** | 在职转行 | 小学 / 中职 | 时间碎片、反感推销 | 早高峰地铁，20 分钟。打开机构 App 先弹 three 秒广告：「我就想刷 10 道题，它非要我先买课。」 |
| **C** | 在校师范生 | 幼儿园 / 中学 | 有基础、缺纪律 | 宿舍熄灯前 15 分钟，躺着刷完一局：「错题第二天就忘了，错题本就是个列表。」 |
| **D** | 二战补弱 | 全学段 | 目标明确、怕无效努力 | 成绩出来差 4 分：「我不知道差在哪个模块，只能从头再背一遍，太亏了。」 |
| **E** | 面试阶段 | 全学段 | 笔试已过、零面试经验 | 笔试通过后一周：「10 分钟无生试讲我一次都没练过，对着空气讲不下去。」 |

**验证方法（onboarding 三问）**：① 报哪个学段 ② 第几次考 ③ 距考试还有多久。三问即可把用户归入上表并给出对应路径。

## 3. 用户真实旅程（对齐官方「六步备考建议」）

```
① 定学段 → ② 定学科（中学） → ③ 规划报考节奏 → ④ 分科突破抓得分重心
                                                        ↓
                                          ⑤ 转面试（试讲+结构化） → ⑥ 普通话+认定
```

| 步 | 用户要什么 | 官方口径 | 当前产品覆盖 |
| --- | --- | --- | --- |
| ① | 我考 2 科还是 3 科？ | §1.1 科目表 | ❌ 无 |
| ② | 中学选哪科？音体美怎么报？ | 15/14 学科；**A 代码规则** | ❌ 无（含 A 代码） |
| ③ | 一次报全科还是分批？哪科会过期？ | 单科 **2 年有效**；面试须全部合格且在有效期内 | ⚠️ 只有考期倒计时，**无有效期统筹** |
| ④ | 时间该花在哪？怎么答？ | 科目一：作文 50 分最大（素材+议论文结构）；职理/德规/法规靠**记忆+材料分析答题模板**；**文化素养靠日常积累，不宜投入过多**。科目二：**教材通读→框架笔记→真题简答/材料题反复练+教学设计模板**。科目三：学科知识+**教学设计大题** | ⚠️ 只做了客观题闯关（39% 卷面）；**答题模板 / 采分点 / 写作训练全缺** |
| ⑤ | 面试怎么练？ | 10 分钟无生试讲；写教案、开口练、录像回看、结构化题库 | ⚠️ 仅「面试轻量版」，排最后 |
| ⑥ | 认定还差什么？ | 合格证明 3 年；普通话二乙/二甲；春秋两批认定 | ❌ 无 |

## 4. 需求定义

> 每条需求必须通过**反玩具检查**：① 哪类用户的哪句口语会用到它？② 不接 LLM 能不能做？③ 有没有可验证指标？三者皆无则砍掉。

### P0 —— 不做用户就无法开始备考

| # | 需求 | 用户口语 | 不接 LLM 能做？ | 关键指标 |
| --- | --- | --- | --- | --- |
| **N1** | **定学段 · 定学科引导**<br>选学段 → 输出考几科、科目二版本、是否考科目三；**内置音体美 A 代码规则** | A：「我到底考 2 科还是 3 科？」 | ✅ 纯规则 | 引导完成率；选错率（A 代码误报拦截数） |
| **N2** | **按考纲组织的内容骨架**<br>知识点树严格对齐官方模块（科目一五维；科目二 7/7/8 模块三版本；科目三 = 学科知识 + 教学能力） | A：「我学的东西就是考的」 | ✅ 数据即结构 | 知识点与考纲条目的覆盖率 |
| **N3** | **分值权重驱动的重点排序**<br>每个考点标「分值权重 × 考频」，直接回答「这 3 小时该背哪块」；**文化素养明确标「低投入」** | D：「我只有两周，背哪块最划算？」 | ✅ 规则+统计 | 重点排序命中率（与真题考点分布比对） |

### P1 —— 决定能不能得分

| # | 需求 | 用户口语 | 不接 LLM 能做？ | 关键指标 |
| --- | --- | --- | --- | --- |
| **N4** | **主观题能力（61% 卷面）**<br>① 材料分析：**答题模板 + 采分点** ② 写作：素材库 + 议论文结构 + rubric-grounded 批改 | D：「材料分析我知道大概意思，但写不出来得分点」<br>A：「作文 50 分我完全是瞎写」 | ❌ 需 LLM（但依据必须来自检索到的 rubric） | 批改与人工评分一致性；四维度评分标准差 |
| **N5** | **真题 × 知识点串联**<br>真题**不入库**（版权），只抽**考点分布与命题角度**，回挂知识点树 | D：「这道题到底考哪个点、考过几次、占几分？」 | ✅ 离线分析一次 | 题目→考点的回挂率 |
| **N6** | **客观题有据训练**（维持）现有闯关 / 复盘 / 错题闭环 | C：「熄灯前刷 10 题」 | ✅ 已有 | 次周留存 |

### P2 —— 完整闭环

| # | 需求 | 用户口语 | 不接 LLM 能做？ | 关键指标 |
| --- | --- | --- | --- | --- |
| **N7** | **报考节奏与有效期看板**<br>各科有效期倒计时、哪科将过期、面试窗口、普通话提醒 | B：「我科目一是去年过的，会不会过期？」 | ✅ 纯规则（成本近零） | 有效期风险提示触达率 |
| **N8** | **面试准备**<br>教案模板、结构化题库、试讲自练（录音/录像回看） | E：「10 分钟无生试讲我一次都没练过」 | 部分（模板/题库纯数据，点评需 LLM） | 面试模块使用率 |
| **N9** | **认定清单**<br>普通话 / 体检 / 材料时间线提醒 | B：「过了之后还要干嘛？」 | ✅ 纯规则 | —— |

## 6. 校准后的目标排序

```
① 领域模型纠偏        （修 D2/D3）        —— 不加题之前先把轴改对
② 报考决策 + 节奏看板 （N1/N7）            —— 零 LLM 成本，直击备考起点
③ 官方语料扩面        （修 D1）            —— 补写作 / 材料分析 / 教学设计 rubric
④ 主观题批改          （N4，61% 卷面）     —— 提到客观题之前
⑤ 客观题有据出题      （N6）               —— 降为维持
⑥ 面试 + 认定         （N8/N9）
⑦ 上传资料出题 / 原文追溯（修 D5）         —— 降级
```

**一句话校准**：
> 从「用 RAG 生成更多客观题」转为「**用考纲结构告诉用户该学什么，用 rubric 帮用户在占 61% 卷面的主观题上拿分**」。
