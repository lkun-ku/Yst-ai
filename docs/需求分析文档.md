## 1. 项目概述

### 1.1 一句话定义

一款微信小程序：**教资考生用碎片时间闯关刷题，每题即时讲解，通关后拿到 AI 复盘报告，并可在考前获得主观题（材料分析、写作）AI 批改。**

### 1.2 从「学任何知识」到「教资《综合素质》」的收敛

初始想法是「输入任何知识 → AI 生成闯关题 → 边答边学」，适用范围极大。经五轮需求追问，收敛为**垂直切入教资赛道**，理由：

| 维度 | 泛知识 | 教资垂直 |
| --- | --- | --- |
| 用户心智 | 无（不知道什么时候该打开） | 强（考期确定，备考 2-3 个月） |
| 复访理由 | 弱 | 强（每天都有该复习的内容） |
| 题目质量可校验 | **无法校验**（用户不知道 AI 编得对不对） | 可对照考纲与真实考试校验 |
| 付费意愿 | 低 | 高（考试结果有真实代价） |
| 获客 | 只能靠内容/口碑 | 考期节点 + 校园/社群传播 |

**结论：泛知识版本不是不能做，而是「没法证明自己做得对」——用户无法判断 AI 生成的冷门知识是否正确。考试场景有标准答案，这是 AI 产品最稀缺的质量校验锚点。**

### 1.3 北极星指标与止损线

- **北极星指标（用户确认）**：正式上线后 4 周内，自然获客 ≥ 500 人，且次周留存 ≥ 20%。
- **止损线**：若上线 4 周后自然获客 < 200 或次周留存 < 10%，停止追加功能投入，转而验证以下两个假设之一：
  1. 是否为「获客渠道」问题（换渠道再验一次）
  2. 是否为「场景选择」问题（转向面试季或 B 端企业培训）

> 注：由于个人主体无法正式发布 AI 生成内容类小程序（见 7.2），**上述指标的验证需在 2026-12 个体工商户主体版本上线后开始计**。内测阶段的验证目标降为：200 名种子用户、次周留存 ≥ 20%、付费意愿访谈 ≥ 10 人。

### 2.3 ⚠️ 改变产品优先级的关键事实

《综合素质》卷面 150 分的构成【二手】：

| 题型 | 分值 | 占比 |
| --- | --- | --- |
| 单选题 | 58 分 | 39% |
| 材料分析题 | 42 分 | 28% |
| 写作题 | **50 分** | **33%** |

模块权重：职业理念 15%、职业道德 15%、教育法律法规 10%、文化素养 12%、**基本能力 48%**。

**推论（本文档最重要的判断）**：

1. 纯客观题闯关只覆盖 39% 的卷面分值，且这部分恰恰是机构题库最全、AI 最没有优势的部分。
2. **写作单项 50 分是整卷最大一题，而机构解析被普遍吐槽「偏重背诵、缺少答题逻辑梳理」**——这是 AI 最擅长且分值最高的缺口。
3. 因此本产品的**核心付费理由不是「无限刷题」，而是「主观题 AI 批改」**。客观题闯关负责获客与留存，批改负责变现。

### 2.4 竞品被吐槽的共性（= 我们的机会）

【二手】高频吐槽：核心功能上锁（免费 20-30%）、题目不全更新慢、解析敷衍、换设备学习记录清零、广告干扰、功能冗余分类粗放。

> 结论：**赛道护城河是题量（我们打不过），痛点在信任与体验（我们打得过）。**

### 2.5 威胁：同名开源项目的重合度

程序员鱼皮《AI 闯关学习小程序》（`liyupi/yu-ai-learn`，2026-08，MIT）已覆盖初始需求 6 条 MVP 中的 5 条、3 条扩展中的 2 条（RAG、AI 生图），技术栈与本产品高度重叠（Taro + FastAPI + LangChain/LangGraph + DeepSeek + 向量库）。**其定位是教学项目，未做商业化与垂直场景。**

> 判断：不构成商业威胁（它不运营），但意味着**技术路径已被验证、无技术壁垒**，我们的壁垒只能来自：垂直内容的正确性、批改质量、以及运营。

## 5. 核心业务流程

### 5.1 闯关主流程（用户侧）

```
打开小程序 → 首页（倒计时 + 今日任务进度 + 「开始闯关」）
   ↓ 选模块/考点，或直接「继续昨日进度」
一次拉取 10 题 → 本地缓存
   ↓ 逐题作答（不请求网络）
答题中：选中 → 即时高亮对错 → 展开解析（含考点标签 + AI 标识）
   ↓ 10 题答完
统一提交 → 生成复盘报告（掌握度 / 薄弱考点 / 下一步一件事）
   ↓
错题自动进错题本（按考点聚合）→ 进入明日任务
```

关键设计约束：
- **一次拉取 10 题、统一提交**：弱网可续答，退出重开不丢进度，同时把 API 调用压到最低。
- **两段式反馈**：先高亮（瞬时）再解析（可延迟），避免遮挡与信息过载。
- **多选题四态**：已选正确 / 已选错误 / 漏选（未选但正确）/ 未选且错误，四色区分，避免「我没错为什么扣分」的困惑。

### 5.2 题目供给管线（生产侧）

```
考纲/考点体系（骨架）
   ↓ AI 按考点生成变式题
结构化校验（JSON schema、单答案唯一性、选项互斥、解析非空、考点归属）
   ↓ 未通过 → 重试/丢弃
人工抽检（按模块设定比例，文化素养模块提高比例）
   ↓ 通过
进入离线题目池 → 对外供给
```

实时生成的**唯一**触发点（成本约束）：
1. 错题即时变式（每人每日上限 3 次，优先从同考点备用题池取）
2. 复盘报告的个性化段落

### 5.3 主观题批改流程（V1.1/V1.2）

```
用户提交作答（材料分析/写作文本）
   ↓ 内容安全检测
AI 按评分维度结构化批改（切题度 / 论据 / 结构 / 语言）
   ↓ 输出：分项评价 + 扣分缘由 + 修改建议 + 示范片段
展示时标注 AIGC 标识 + 「AI 仅供参考」免责说明
```

### 5.4 审校规则（质量红线）

| 模块 | 风险 | 规则 |
| --- | --- | --- |
| 职业理念 / 职业道德 | 中 | 标准抽检比例 |
| 教育法律法规 | 中高（条文引用易错） | 提高抽检比例；答案须能指向具体法规 |
| **文化素养** | **高**（常识/历史/科技最易编错） | **最高抽检比例**；只出确定性高的事实题；存疑即弃 |
| 基本能力（逻辑/信息处理） | 中 | 逻辑题须可推导验证 |
| 材料分析 / 写作批改 | 中高 | 必须附免责说明，不承诺与官方评分一致 |

## 6. 领域模型

完整术语定义见 [`CONTEXT.md`](../CONTEXT.md)。核心概念关系：

```
考期 ──决定──> 每日任务 ──包含──> 闯关局 ──产生──> 复盘报告
                                    │                  │
                                    │                  └── 更新 ──> 掌握度
                                    └── 答错 ──> 错题本（按考点聚合）
考点 ──归属──> 模块（五维，有官方权重）
考点 ──生成──> 变式题 ──审校通过──> 题库 / 离线题目池
知识库（考纲/教材/用户上传）──作为依据──> 变式题
```

三条必须守住的语言纪律：
1. **题库 ≠ 知识库**：前者是可作答的题目集合，后者是出题依据的原始资料。
2. **变式题 ≠ 原题**：产品内只存在变式题；原题仅作考频分析对象，不入库、不展示。
3. **离线题目池 ≠ 题库**：前者强调供给方式（预生成可直发），后者强调内容状态（已审校可用）。

## 7. 合规与风险（能不能上线，优先于想不想做）

### 7.1 主体资质：必须先注册个体工商户

| 事项 | 结论 | 来源 |
| --- | --- | --- |
| 个人主体能否提供 AI 生成内容服务 | **不能**。只要调用大模型 API 生成/处理内容，可能被认定使用深度合成技术；「深度合成 - AI 问答」类目个人主体尚未开放 | 【官方】微信开放社区答复；多方审核案例 |
| 个人主体能否虚拟支付 | **可以（2026-04-15 新规）**，但限工具类目、月限额 10 万、Android 费率 1% / iOS 12%、仅支持道具直购、iOS 需微信 ≥8.0.68 且配置小程序简称 | 【官方】微信开放文档「虚拟支付：个人」 |
| 个人主体能否变更为个体工商户/企业 | **不能**。主体变更要求新旧主体均为企业/个体户/组织 | 【二手】多篇主体变更实操指南一致 |
| 结论 | **写第一行生产代码之前完成个体工商户注册**。否则换 AppID、openid 全部作废、用户数据清零 | 【本文结论】 |

> **已确认决策**：先用个人主体做内测验证，验证通过后再注册个体工商户正式上线（接受换 AppID 的代价）。**必须在 2026-11 前完成注册与类目申请，否则赶不上 12 月上线窗口。**

### 7.2 深度合成类目与算法备案

- 需申请「深度合成 - AI 问答」服务类目。
- 若**不自研算法**、仅调用已备案的第三方大模型服务，则可走「提供第三方已备案算法服务资质」的路径，避免自建算法备案的长周期。
- 需完成小程序认证、ICP 备案、服务器域名白名单配置。

### 7.3 AIGC 标识（强制义务）

【官方】《人工智能生成合成内容标识办法》（2025-03-14 发布，2025-09-01 施行）要求对文本等生成内容添加**显式标识**（界面可感知）与**隐式标识**（元数据）。

落地要求：
- 题目卡片或解析区固定标注 AI 生成标识
- 复盘报告与批改结果明确标注，并附「AI 生成内容仅供参考」
- 首次使用时说明一次，不重复打扰

### 7.4 题库版权

- 历年原题受著作权保护，未经许可的复制、传播、商业使用可能构成侵权；个人学习少量使用属合理使用例外。
- **已确认策略：不存储、不展示原题原文。** 以官方考纲与考点体系为骨架，AI 自研变式题；原题仅用于分析考频与考点分布。
- 用户通过 RAG 上传的资料由用户自行负责权属，需在上传协议中明确。

### 7.5 分享与裂变红线

【官方】诱导分享、诱导关注属于平台重点治理行为。**禁止**：分享才能解锁、分享得补签卡、分享得题量。**允许**：用户自愿分享复盘报告海报、自愿邀请好友组队（无任何权益绑定）。

### 7.6 内容安全

用户输入（自由文本、上传资料）与 AI 生成内容均需过微信内容安全检测接口；未通过的内容不得展示或入库。

## 8. 技术与成本方案

### 8.1 技术选型（已确认，此处只记录与论证）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 小程序前端 | Taro 4 + **Vue 3** + TypeScript + NutUI + Pinia | Taro 官方支持 Vue 3；**只做微信单端**，不承诺多端（Vue 3 在 Taro 生态中的资料少于 React，多端适配有已知边角问题） |
| 后端 | Python 3.11 + FastAPI + LangChain / LangGraph | AI 编排生态最成熟，RAG 与结构化输出现成 |
| 数据 | MySQL + 向量库（Chroma 或同类） | 向量库用于 RAG 知识库 |
| 部署 | Docker + 微信云托管 | — |
| 大模型 | 推理模型用于出题/批改/报告；国内平台用于 Embedding | 不接入 AI 生图 |

### 8.2 成本测算（预算 ≤300 元/月）

**计算假设【估算】**（汇率按 1 USD ≈ 7.2 CNY；DeepSeek V4 Flash 高峰价 $0.44/M 输入、$1.32/M 输出【二手】；2026-04-25 起为峰谷分时计价，闲时更低）：

| 动作 | 输入 tokens | 输出 tokens | 单次成本 |
| --- | --- | --- | --- |
| 生成 1 道变式题（题干+4选项+答案+解析） | ~1,000 | ~600 | ≈ 0.009 元 |
| 生成 1 份复盘报告（全 AI） | ~1,500 | ~800 | ≈ 0.012 元 |
| 生成 1 份复盘报告（模板化，AI 只写个性化段落） | ~1,500 | ~300 | ≈ 0.007 元 |
| 1 次主观题批改 | ~2,500 | ~1,200 | ≈ 0.020 元 |

**三档方案对比（以 500 DAU、每人每日 20 题、30 天计）**：

| 方案 | 月成本 | 可行性 |
| --- | --- | --- |
| A：全部实时生成 | 300,000 题 × 0.009 ≈ **2,700 元** | ❌ 超预算 9 倍 |
| B：池化为主 + 报告模板化 + 变式限次 | 预生成 1 万题 90 元（一次性）+ 报告 ≈ 98 元 + 变式 ≈ 81 元 + 服务器 100-250 元 ≈ **280-430 元** | ⚠️ 需三项优化才压得住 |
| C：全离线（报告也模板化，无实时变式） | 服务器 100-250 元 + 预生成摊销 ≈ **150-300 元** | ✅ 但体验受损 |

**结论：采用方案 B，并设为硬约束：**

1. **池化率 ≥ 95%**：题目供给以离线题目池为主，实时生成占比不得超过 5%。
2. **报告模板化**：固定结构由代码生成，AI 只写个性化段落（成本降约 40%）。
3. **变式题优先取池**：错题变式先从同考点备用题池取，池空才实时生成；每人每日实时生成上限 3 次。
4. **闲时批量生成**：利用峰谷分时计价的闲时窗口批量扩充题目池。
5. **监控**：对实时生成调用量设日级告警，超预算自动降级为纯池化供给。

> ⚠️ 服务器费用为【估算】（微信云托管按量计费 + 云数据库，最低配约 100-250 元/月），实际以官方器定价为准。

### 8.3 三个残余张力（显式记录，不回避）

| # | 张力 | 处理 |
| --- | --- | --- |
| 1 | **预算 ≤300 元/月 ↔ 实时 AI 出题** | 已通过「两条腿」策略化解：离线预生成题目池为主供给，实时生成只服务错题变式与复盘报告（8.2 的硬约束） |
| 2 | **师范生付费能力弱 ↔ VIP 订阅变现** | 转化窗口集中在考前 1 个月；免费额度设计为「平时够用、冲刺期不够用」；客单价定在 30-100 元的冲动消费区间，而非机构年费量级 |
| 3 | **文化素养模块最易被 AI 编错** | 该模块执行最高人工抽检比例；只出确定性高的事实题；存疑即弃；可考虑初期对该模块降权 |

## 9. 商业化设计

### 9.1 免费额度（已确认：每日 1000 题）

> **2026-05-25 修订**：原定「每日 20 题」。内测期为避免额度紧箍咒干扰验证，经确认改为 **每日 1000 题**（`quota.FREE_DAILY_LIMIT = 1000`）。商业化阶段再按 9.2 的转化窗口设计回调。测试不再硬编码数值，改为引用 `FREE_DAILY_LIMIT` 常量。

设计原则：**按题量限速，不按内容范围设限**——所有考点永远可刷，只对每天能做多少题限速。这是与「免费 20-30%、核心上锁」的机构产品最大的体验差异，也是口碑来源。

| | 免费考生 | VIP |
| --- | --- | --- |
| 每日题量 | 20 题 | 不限 |
| 覆盖范围 | 全部模块与考点 | 全部模块与考点 |
| 复盘报告 | 基础版（掌握度 + 薄弱考点） | 深度版（+ 个性化建议 + 学习路径） |
| 错题变式 | 每日 3 次 | 不限 |
| 知识库上传（RAG） | — | 支持 |
| 材料分析批改（V1.1） | — | 每月 N 次 |
| 写作批改（V1.2） | — | 每月 N 次 |

### 9.2 定价建议

参考竞品年费 398-790 元【二手】，但那是含课程与教研的机构定价，纯工具不可对标。建议显著低于该区间，主打冲动消费：

- 包月：29-39 元
- **考前包季：69-99 元**（冲刺期主推，客单价与转化率最优）
- 支持 0 元试用 + **到期前主动提醒**（借鉴 Duolingo：看似吃亏，实则提升转化与信任）

### 9.3 收入测算（【估算】，属「若达成」场景而非预测）

假设 MVP 期末 MAU 3,000、付费转化率取行业下限 2%【二手】：

- 付费用户 60 人 × 39 元/月 ≈ **2,340 元/月**
- 成本约 300 元/月 → 毛利率约 87%

> ⚠️ 该测算的前提是 MAU 达到 3,000，属于达成北极星之后的乐观场景。**在 MAU < 1,000 时，本项目不应视为有收入预期的商业项目。**
