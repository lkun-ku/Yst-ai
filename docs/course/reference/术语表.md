# 术语表

> 课程中统一使用这些术语。读到不懂的词先查这里。
> 每条给出「一句话定义 + 本项目里的对应代码」。

## A · 检索与向量

| 术语 | 英文 / 缩写 | 一句话定义 | 本项目位置 |
|---|---|---|---|
| 嵌入 / 向量化 | Embedding | 把一段文字变成一串数字（向量），语义相近则向量相近 | `embedding.embed_one` |
| 向量 | Vector | 一组浮点数，本项目的维度是 1024 | `document_chunks.embedding` |
| 余弦相似度 | Cosine Similarity | 两个向量夹角的余弦值，只看方向不看长度，范围 -1~1 | `embedding.cosine_similarity` |
| 点积 | Dot Product | 两向量逐元素相乘再求和；单位向量间的点积 = 余弦相似度 | `vector_rank` 里的 `mn @ qn` |
| 广播 | Broadcasting | numpy 在形状不匹配时自动扩展维度（对齐顺序**从右往左**） | `keepdims=True` 那行 |
| 归一化 | Normalization | 把向量缩放成单位长度（模长 = 1） | `q / (np.linalg.norm(q) + 1e-12)` |
| 切片 | Chunk | 把长文档切成的片段，本项目的默认大小是 1500 字 | `doc_parser.split_chunks` |
| 重叠窗口 | Overlap | 相邻切片共享的字符数，防止切分点切断语义 | `doc_chunk_overlap = 200` |
| 双塔 | Two-Tower / Bi-encoder | 查询和文档各自独立编码成向量，互不影响 | `embed_one` 分别用于两者 |
| 召回 | Recall / Retrieval | 从全量语料中粗筛出候选集（后续再精排） | `retrieve_by_scope` |
| RRF | Reciprocal Rank Fusion | 多路召回融合：只用排名不用分数，`Σ 1/(k+rank)` | `kb_retrieval.rrf`，`k=60` |
| 三级降级 | Fallback Chain | 向量 → 关键词 → 均匀采样，保证永不返回空 | `embedding.retrieve` |
| 均匀采样 | Uniform Sampling | 等间隔取样，保证覆盖首尾而非只取开头 | `embedding.uniform_sample` |
| 二元组 | Bigram | 中文没空格，所以按连续 2 字切分做关键词匹配 | `embedding._terms` |
| 硬过滤 | Hard Filter | 先用字段精确筛（如 `kp_id`），再做语义召回 | 规划中（P2） |
| HNSW | Hierarchical Navigable Small World | pgvector 的近似最近邻索引，用于加速向量检索 | `alembic/` 迁移里的索引 |
| pgvector | — | PostgreSQL 的向量扩展，提供 `vector` 类型与 `<=>` 算子 | `retrieve_by_scope_pg` |
| 余弦距离 | — | `1 - 余弦相似度`，pgvector 的 `<=>` 返回的是它 | `1 - (dc.embedding <=> ...)` |

## B · RAG 与生成

| 术语 | 英文 / 缩写 | 一句话定义 | 本项目位置 |
|---|---|---|---|
| RAG | Retrieval-Augmented Generation | 检索增强生成：先找资料再问模型，把「闭卷」变「开卷」 | `kb_generate.generate_by_scope` |
| 幻觉 | Hallucination | 模型编造出看似合理但实际错误的内容 | 靠 `source_id` 校验来检测 |
| LLM as Judge | — | 让大模型充当评判者，对内容打分或判定 | `_grade_and_filter`、`_selfcheck_batch` |
| 自检 | Self-check | 让模型审查自己刚生成的题目是否忠于原文 | `prompts_kb.self_check_prompt` |
| 查询改写 | Query Rewriting | 把口语化/过宽的查询改写成更利于检索的形式 | `scope_rewrite_prompt`，限 1 次 |
| 降粒度重试 | Granularity Backoff | 批量生成失败时二分缩小批量（3→2→1）重试 | `_generate_batch_with_fallback` |
| 补偿轮 | Compensation Round | 题量不足时再生成，带余量后按需截断 | `compensation_count`，最多 5 轮 |
| 抽检升级 | Escalating Sampling | 先抽检 2 题；发现不合格则升级为全批检 | `_selfcheck_batch` 的递归分支 |
| 验收抽样 | Acceptance Sampling | 统计学方法：低成本放行好批次，可疑批次付全价检查 | 同上 |
| 受约束生成 | Constrained Generation | 给模型有限的候选集，输出后校验是否落在集合内 | `picked_ids_of` 白名单校验 |
| 溯源 | Provenance / Traceability | 记录题目依据的原文，可回查 | `Question.source_chunk` |
| 批级溯源 | — | 记录整批召回的切片 id（精度较低） | `doc_generate.build_source_chunk` |
| 逐题溯源 | — | 模型回传该题具体依据的切片 id（精度较高） | `source_id` 字段 |
| 布鲁姆分类学 | Bloom's Taxonomy | 认知层级：记忆→理解→应用→分析→评价→创造 | `prompts_kb.BLOOM_DESC` |
| 干扰项 | Distractor | 选择题里的错误选项，质量决定题目难度 | 规划中要求「来自常见误解」 |
| 难度自适应 | Adaptive Difficulty | 根据掌握度调整出题难度 | 规划中（需先补 `difficulty` 列） |

## C · 数据与持久化

| 术语 | 英文 / 缩写 | 一句话定义 | 本项目位置 |
|---|---|---|---|
| 事件溯源 | Event Sourcing | 只存「发生过什么」，状态由事件流算出 | `ChatTurn`、`KbTaskEvent` |
| 投影 | Projection | 把事件流折叠成一个状态 | `chat._current_question` |
| 快照 | Snapshot | 把易变过程在某一时刻固化成不可变记录 | `Session.question_ids` |
| append-only | — | 只追加不修改的写入模式，写入是 O(1) | 事件表的设计理由 |
| 游标 | Cursor | 单调递增的序号，用于增量拉取 | `KbTaskEvent.seq` |
| 幂等 | Idempotency | 同一操作执行多次，结果与执行一次相同 | `Session.result_json` 缓存 |
| MVCC | Multi-Version Concurrency Control | 多版本并发控制：事务读取的是开始时的快照 | `wait_embed_ready` 里的 rollback |
| 事务隔离级别 | Isolation Level | 控制事务间可见性的规则（可重复读…） | 同上 |
| 悬空指针 | Dangling Reference | 引用了已被删除的记录 | JSON 列存 id 的风险 |
| JSON 列 | — | 把结构化数据塞进一个文本列，只整体读写 | `Session.question_ids` |
| 迁移 | Migration | 数据库结构变更的版本化脚本 | `alembic/versions/` |
| 分方言处理 | Dialect Dispatch | 同一段代码在 SQLite / PostgreSQL 上走不同实现 | `_is_pg(db)` 分支 |

## D · 架构与设计

| 术语 | 英文 / 缩写 | 一句话定义 | 本项目位置 |
|---|---|---|---|
| 接缝 | Seam | 能在不改代码的前提下替换实现的位置 | `get_llm_client()` |
| 依赖倒置 | DIP | 高层和低层都依赖抽象，而不是互相依赖 | `LLMClient` 抽象基类 |
| 控制反转 | IoC | 不自己创建依赖，而是声明需要什么 | FastAPI `Depends` |
| 依赖注入 | DI | 由外部把依赖传进来，而非内部 new | `deps.get_current_candidate` |
| 策略分派 | Dispatch | 主函数只路由，具体实现按类型分派 | `sessions._judge` |
| fail-open | — | 失败就降级放行，不阻塞主流程 | embedding、自检、检索 |
| fail-close | — | 失败就报错，绝不糊弄过去 | 评分、内容安全 |
| 协作式取消 | Cooperative Cancellation | 被取消方在安全点主动检查并优雅退出 | `should_stop()` |
| 线程池饥饿 | Thread Pool Starvation | 等待任务占满槽位，被等的任务无法获得槽位 → 死锁 | gen / embed 分池的理由 |
| 命名空间 | Namespace | 同一语料层里按可见范围划分的分区 | 规划中的 official / personal |
| 覆盖度 | Coverage | 某知识点已有多少题 / 缺多少题 | `knowledge_points` 树的用途 |
| 领域模型 | Domain Model | 业务概念的抽象结构（科目/学段/模块/知识点） | `Subject`/`Stage`/`KnowledgePoint` |

## E · Python 与并发

| 术语 | 英文 / 缩写 | 一句话定义 | 本项目位置 |
|---|---|---|---|
| GIL | Global Interpreter Lock | CPython 中同一时刻只有一个线程执行字节码 | 决定线程池适用场景 |
| IO 密集 / CPU 密集 | IO-bound / CPU-bound | 时间花在等待 / 花在计算 | 出题是 IO 密集 → 线程池 |
| 闭包 | Closure | 函数记住了它定义时所在作用域的变量 | `generate_by_scope` 里的 `emit` |
| 哨兵值 | Sentinel | 用 `None` 作为「未提供」的标记 | 所有 `xxx=None` 默认参数 |
| check-then-act | — | 先查询再据此写入，并发下会读到同一旧值 | `_add_turn` 的 `count()+1` |
| 延迟导入 | Lazy Import | 把 import 放进函数体，避开循环依赖 | `doc_generate.fallback_generate` |
| 抽象基类 | ABC | 不能实例化、强制子类实现方法的类 | `llm_client.LLMClient` |
| 高階函数 | Higher-order Function | 接收或返回函数的函数 | 装饰器的基础 |
| 类型注解 | Type Annotation | 标注参数与返回值类型，**运行时不做检查** | 全项目 |

## F · 教资业务

| 术语 | 含义 |
|---|---|
| 科目一 / 综合素质 | 教资笔试第一科，本项目的**唯一覆盖科目** |
| 科目二 / 教育知识与能力 | 教资笔试第二科（未覆盖） |
| 科目三 / 学科知识与教学能力 | 教资笔试第三科，按学科分（未覆盖） |
| 学段 | 幼儿园 / 小学 / 中学，三科考纲按学段不同（未建模） |
| 五维模块 | 综合素质的五个模块：职业理念 / 职业道德 / 教育法律法规 / 文化素养 / 基本能力 |
| `OFFICIAL_MODULES` | 项目里表达「官方五维」语义的**唯一常量**，禁止直接遍历 `Module` |
| `PERSONAL` | 用户资料生成题的独立维度，**不参与**官方统计 |
| 模考 | 按卷面权重抽题 + 限时的仿真考试（`MODE=mock`） |
| 卷面权重 | 各模块在真实考卷中的占比（`MOCK_WEIGHTS`） |
| 变式题 | 基于同一考点、换情境/换角度的题目 |
| 真题考点改编 | 只取真题的「考点 + 题型 + 难度 + 命题角度」，**不存原文** |
