### `backend/app/services/` —— 服务层

| 文件 | 职责 | 依赖关系 |
|---|---|---|
| `llm_client.py` | **唯一 AI 出口**（Fake/Real 双实现） | 被所有生成链路依赖 |
| `prompts_kb.py` | 出题/评分/自检/改写提示词与解析 | 被 kb_generate / llm_client 用 |
| `embedding.py` | 向量编解码、单文档检索、三级降级 | 被 kb_retrieval 复用 |
| `kb_retrieval.py` | 跨文档混合检索（RRF） | 依赖 embedding |
| `doc_parser.py` | PDF/Word/TXT 解析与两级切分 | 被 documents 用 |
| `doc_generate.py` | 单文档出题编排 + 落库去重 | 与 kb_generate **互相延迟导入** |
| `kb_generate.py` | 跨文档出题质量闭环（路线②） | 复用 doc_generate 的落库 |
| `kb_graph.py` | LangGraph 编排版（路线③，实验性） | 与 kb_generate 共享接缝 |
| `kb_events.py` | 出题过程事件写入 | 被 documents / tasks 用 |
| `validation.py` | 题目结构化校验 + 答案归一化 | 被生成链路与判分用 |
| `task_pool.py` | gen / embed 分池线程池 | 被 documents 用 |
| `realtime.py` | 实时用量与池化率监控 | 被 review / admin 用 |
| `proofread.py` | 抽检抽样 | 被 admin 用 |
| `content_safety.py` | 文本安全检测（wx msgSecCheck / stub） | — |
| `voice.py` | ASR / TTS | 被 chat 用 |
| `streak.py` | 连胜计算 | 被 streak 路由用 |

## 三、测试与验证

| 想做的事 | 命令 |
|---|---|
| 跑全量后端测试 | `cd backend && python -m pytest` |
| 跑单个模块 | `cd backend && python -m pytest tests/test_chat.py` |
| 启动后端 | `cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000` |
| 前端语法检查 | 对改动文件 `node --check <file>` |
| 冒烟测试 | `backend/一键冒烟测试.bat` |
| HTTP 冒烟 | `python backend/scripts/smoke_doc_api.py` |

**仓库作业纪律**（见 `AGENTS.md`）：
改动前 `git stash` 或建分支；修复后跑 `pytest` 全量 + 前端 `node --check`，确认无回归。
