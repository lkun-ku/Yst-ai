# 优师通备考小程序 · 源码精读课

> 这套课程用**你自己的代码**当教材。每一节都从一个真实功能出发，讲清它「为什么这么设计」，
> 再顺手把背后的 Python 语法与工程原理补上。

## 这套课程和 `docs/` 其他文档的区别

| 文档 | 写给谁 | 内容 |
|---|---|---|
| `docs/项目技术深度文档.md`、`docs/RAG与题库技术选型方案.md` | 项目本身 | 方案、选型、决策依据 |
| `docs/adr/*.md` | 未来维护者 | 单个决策的背景与后果 |
| **`docs/course/*`（本目录）** | **你（学习者）** | **功能怎么实现的、原理是什么、怎么自己验证** |

课程会大量引用既有文档，但不会重复它们的内容。

## 怎么用这套课程

**建议节奏：一次一节，每节 40～60 分钟。** 每节的结构固定：

```
① 本节要讲的功能 + 学习目标
② 心智模型（先用一句话讲清本质）
③ 主干流程（一张图）
④ 核心代码逐段拆解（含「为什么不用另一种写法」）
⑤ 已知缺陷（供后续改造）
⑥ 检索练习（先自己做，再看答案）
⑦ 延伸阅读（primary source）
```

**关键原则：不要只读。** 每节末尾的练习是设计过的，做不出来说明还没真正理解。
做不出来的地方，直接问我（我是你的老师，可以就任何细节展开）。

## 前置知识

- 会写 Python 的基础语法（变量、函数、类、`for`/`if`）
- 知道 HTTP 请求/响应与 JSON 是什么
- **不需要**懂 SQL、向量检索、大模型 —— 第 02 节会从零讲

## 阅读约定

- 代码引用格式为 `文件路径:起始行-结束行`，可直接在编辑器里跳转
- 标注 **【原理】** 的是通用知识（换个项目也用得上）
- 标注 **【本项目】** 的是仅适用于当前代码库的知识
- 标注 ⚠️ 表示已知缺陷或坑
